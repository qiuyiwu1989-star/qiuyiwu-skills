# 完整示例：AI 录音胸牌（"AI 的耳朵"）

来源：2026-11-11 会议。以下 KANO 为**专家推演，待问卷验证**。

## 1. 角色地图
孩子（使用者）· 家长（付费者）· 祖辈/育儿嫂（受影响者）· 老师（使用者/受影响者）· 校长/园长（决策者）· 教育局（政策方）

## 2. Job Story 节选
| # | 角色 | Job Story | 出处 |
|---|---|---|---|
| J1 | 家长 | 当孩子刚入托/入园、第一次离开我的视线，我想知道他一天是否安好、经历了什么，以便晚上正确地陪伴他 | 诗中、胡艺 |
| J2 | 家长 | 当孩子突然情绪异常（哭、不说话），我想找到原因，以便判断是否需要干预 | 邱懿武"在幼儿园哭了我也不知道为什么" |
| J3 | 特殊儿童家长 | 当老师反映孩子在校有问题，我想拿到客观多视角的证据，以便说服家人、和学校达成一致 | 陈晓案例 |
| J4 | 家长 | 当老人/育儿嫂带孩子，我想知道他们的说话方式是否符合我的理念，以便及时沟通 | 胡艺 |
| J5 | 家长 | 当我拿到孩子的报告，我想得到具体可执行的陪伴方法，以便不用自己再去查 | 邱懿红"拿到手就能用" |
| J6 | 家长 | 当孩子处在语言/社交关键期，我想及时捕捉变化，以便不错过干预窗口 | 慧娴妹妹案例 |
| J7 | 老师 | 当期末要交课题/论文，我想从日常课堂中自动获得数据和选题，以便不额外加班就出成果 | 方颖、邱懿红 |
| J8 | 老师 | 当家长不认可我对孩子的判断，我想有客观记录，以便有依据地沟通 | 融合教育讨论 |
| J9 | 校长 | 当评价改革要求过程性数据，我想低负担地采集全校教学数据，以便出办学特色成果 | 方颖 |
| J10 | 家长 | 当孩子度过特别的一天，我想把它变成以孩子为主角的绘本，以便留下纪念、亲子共读 | 胡艺 |

## 4. 风险（焦虑之阻）
孩子带设备进校被禁止；老师怕被监控；录到他人隐私；需求阶段性（四五年级后孩子抵触）。

## 5. 概念验证
海报 1：《他第一天上托班，门关上之后》 · 海报 2：《老师又来电话了，这次我有了依据》 · 海报 3：《期末课题，课堂已经替你写好了一半》——发给 10 位家长/老师投票。
