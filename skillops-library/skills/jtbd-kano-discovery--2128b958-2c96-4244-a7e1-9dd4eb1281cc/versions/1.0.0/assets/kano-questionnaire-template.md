# KANO 问卷模板

## 问卷说明（发给用户）
以下每个功能有两道题，请凭第一感觉选择。
选项：1 我很喜欢 / 2 理所当然 / 3 无所谓 / 4 勉强接受 / 5 我很不喜欢

## 题目（每条需求生成一对）
**需求 {编号}：{用用户的语言描述的需求，不用技术词}**
- Q{编号}+ 如果产品能 {需求}，你感觉如何？ ①②③④⑤
- Q{编号}− 如果产品不能 {需求}，你感觉如何？ ①②③④⑤

（可选）付费意愿：如果这个功能单独收费，你愿意每月付多少？

## 回收数据 CSV 格式（供 scripts/kano_score.py 使用）
长格式，每行一个受访者对一条需求的回答：
```csv
respondent,segment,feature,functional,dysfunctional
r1,家长,入托期每日安好报告,1,5
r1,家长,定制绘本,1,3
r2,老师,课堂数据自动出选题,1,4
```
- functional / dysfunctional：1–5 的数字（也可填中文选项文本：喜欢/理所当然/无所谓/勉强接受/不喜欢）
- segment：人群分组，可选；填写后脚本按人群分别统计
