# RC-010 复古漫画新粗野主义

文字、图形、关系和留白用图像工具共同生成整页。示例在 assets/，选择相关页型作参考，不复制示例内容为用户事实。


## 内容优先的表达构思

先理解内容，再设计讲法，最后应用视觉风格。本节优先于本Skill中的示例布局、默认页型及页数建议；用户明确指定的布局仍应遵守。模板固定视觉语言，不固定故事结构与构图。

生成前先形成一份简短表达简报：听众是谁；希望其理解、感受或采取什么行动；核心主张是什么；必须保留的事实、证据、限制与情绪转折是什么。已有信息足够就直接判断，不机械追问；只有影响讲法的关键缺失才询问。

根据内容选择叙事逻辑：故事按处境、变化、选择与结果推进；观点用依据、例子与成立条件支撑；机制明确参与者、作用和反馈；方法展示任务、操作与关键判断；选择按同维度比较与适用条件展开；文化表达可从生活细节、器物或场景进入。以上是候选讲法，不是另一组强制模板，允许混合或另创。

只有存在实质不同的讲法且用户尚未指定时，提出两种简短方向，解释各自突出什么；普通单页可自主选择，不把每次创作变成审批流程。单页确定表达任务，整套安排进入、推进、转折与停顿，再决定页数、构图、字图比例和视觉节奏。

封面、观点、对比等页型是参考词汇，不是必须凑齐的目录。允许纯文字页、证据页、连续场景或用户内容所需的新页型。不要为了套三步骤而改写过程、为了闭环添加因果、为了风格强放人物或器物；不能用通用口号替代原始细节。插画须解释动作、关系、证据或情绪，否则删掉或改为留白。

验收先看内容：能否说清本页为何采用这个讲法、图像增加了什么理解；原始事实、限定、情绪和关系是否保留；是否因套版发生删减、伪造或过度概括。再检查视觉一致性、文字可读性与尺寸。跨页保持字体、配色、笔触与必要角色一致，布局随内容变化。


## 风格不变量

- 暖奶油纸底 #F1DFC2，近黑 #191916、灰粉 #EA8BA5、青绿 #59A894、暖橙 #EF762A，少量黄。复古色以面板组织，避免高饱和蓝黄红贴纸风混入。
- 超粗几何中文黑体标题，略有手工印刷的不规则边缘；正文清晰中粗黑体。标题允许巨大，但不能侵占正文可读空间。不要用毛笔字、花体或伪英文。
- 厚圆角黑边、轻网点与套色印刷感；网点不能盖住正文。一个主场景或少量语义图标，不把每页做成复杂海报。
- 默认四边9%内容安全区、约30%呼吸空间。参考样张有些版式偏满，不继承其顶边问题；内容不够放时缩减图景或拆页。

## 角色与物件

角色可选：原创成年创作者搭档。一位短黑发、圆眼镜、奶油棒球帽、青绿色外套；另一位短卷发、奶油衣与青绿围巾。动作根据内容变化，不强制每页出现。需要同人时用封面与尾页原创参考锚定。

橙色复古小巴是“出发/行动”的可选叙事物件，铅笔、地图、样机与笔记用于对应动作。其他项目可替换物件，不能无论主题都放汽车。默认不采用第三方参考的骷髅角色、品牌或原有文案。

## 页意与密度

先确认听众应记住的一句话，再保留解释、证据与条件。数据、限制、否定与责任主体不可因美观静默删改。短文用大字和单场景；中文约80字以上开始减少人物与背景；字再多先分组，再考虑拆页，不缩成小字。阈值是提示，不取代实际可读性检查。

八种页型：
- COVER：强主张加单幅叙事场景，首尾角色一致。
- SECTION：编号、转折句、一个物件，避免内容页的密集度。
- CLAIM：观点与解释分两级，插画只支撑一个隐喻。
- COMPARE：同一维度逐项对齐，双方文字与图的权重相称，不虚构比较结果。
- STEPS：编号、动作、必要说明；三步是样例，按实际步骤调整。
- CYCLE：只在真实反馈机制存在时使用闭环，逐一核对方向。
- SYSTEM：分组、层级与连接优先，人物可去掉；不能把所有系统强行简化成三块。
- END：短行动句、致谢，可留后贴二维码区域，不生成假二维码。

## 生成与验收

提示词明确准确上屏文字、页型、布局、配色、角色是否出现和安全区。使用当前图像工具；不能用HTML拼文字与配图冒充整页生成。

默认横版1920×1080。实测原生与成品尺寸并记录，极小整数比例差可规范化，明显比例差应重新生成或等比适配，不能明显拉伸。避免补底色差形成不必要边框。

检查文字、层级、角色、箭头、边缘与小屏可读性。八页样例是原创候选，不等于用户逐页认可；公开发布须有对应授权。交付集中放在既有创作工作区，保留原图、成品、提示词与规格。
