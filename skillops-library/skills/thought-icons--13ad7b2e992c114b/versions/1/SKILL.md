# 思想的符号

与「思想的形状」共享清润、疏朗的气质，但以小尺寸识别为第一约束。参考用户提供的深底白线分类图标，只借鉴笔触、视觉重量与一致性，不照搬轮廓。

## 区分用途

- 功能图标：采用熟悉的语义，如文档、搜索、任务；统一线宽与视觉尺寸。
- 产品标识：先理解产品的核心动作，再创造可记忆的独特轮廓。不要把每个产品都画成文件夹、脑或齿轮。衍生客户端可共享主标识并有明确变体。
- 应用商店图标：根据具体平台再查交付规格，不把网页圆角底座直接当作最终商店文件。

## 设计规则

默认 editable SVG，64×64 viewBox，主体位于 12–52 安全范围，约 1.7–2 单位线宽，圆端点与圆连接。允许少量曲线偏离机械对称，但不随机抖动、不用噪声滤镜、不叠多条线模拟毛边。

每枚一个主轮廓、最多两处辅助细节；使用负空间形成识别。默认 currentColor，符号与底座分离。浅色墨灰/暖白，深色月白/炭灰；青瓷、藕灰、茶灰作为可选点缀，不能仅靠颜色区分。

先在64px设计，再检查32、24、16px。16px可单独简化路径与调线宽，不机械等比缩小复杂图；正式交付注明已验证尺寸。复杂刻线、纸纹、山水不进入小图标。插画缩略图不能直接当icon。

## 工作流程

读取现有品牌资产和组件，已有正式标识时优先沿用或设计兼容变体，不擅自替换。确认图标清单与语义，先画一小组代表性样例并展示深浅底、大图及小尺寸。用户给风格调整时改变指定维度并保持同系列一致性。

生成SVG时优先直接编辑路径；新颖位图概念探索可用图像生成工具，但最终SVG必须可编辑并人工检查，不能包装一张PNG假装矢量。

集合建立 manifest：id、名称、用途、隐喻、家族、SVG路径、支持尺寸、版本和审阅状态。样例是提案，不代表用户已认可。最终交付SVG源文件、预览页，按需导出PNG。网页接入需验证图标加载、视觉对齐、深浅主题与无障碍：装饰图标aria-hidden；独立按钮使用可访问名称。

参考 [样例说明](references/examples.md) 和 assets 下的SVG起点。保持发布和替换品牌资产的授权范围。

## 路径连接检查
圆弧 A 使用绝对终点，a 使用相对位移，禁止混用。连接处端点必须落在目标路径上；封闭轮廓用 Z，叠页须处理遮挡，不能用加粗掩盖断口。保留有语义的独立笔画。检查修改后同步 SVG、JS 映射、内联预览与 Skill 副本。
