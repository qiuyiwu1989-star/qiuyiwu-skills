# 信源层级：一手 / 二手 / 三手

> 阅读档案的「信任度量尺」。回答一个问题：**这份档案里的判断，能信到什么程度、要不要回原处核。**

---

## 一、三档定义

| 档位 | 含义 | 例 |
|------|------|-----|
| **一手** | 直接读到的**原始材料**——原话、原文、原始报告、播客/视频逐字稿、官方文档 | Palantir 官方文档原文；YC 视频逐字稿；用户直接粘贴的正文 |
| **二手** | 对一手的**转述/提炼/编译**，但仍标明了原始出处 | 公众号拆解某期播客（附原视频链接） |
| **三手** | 对二手/多来源的**再转述**，来源不可考或未注明 | "有消息称…"、无出处的"某研究"、群里转发的截图 |

**为什么分档**：一手没被"提炼掉为什么"；二手替人省了时间但也可能**失真或夹带立场**；三手则可能已经是"传话游戏"的末端。

---

## 二、写法

- **必写档位**：`- **信源层级**：二手（原始出处：<播客/报告名 + 链接>）`
- **二手/三手**：能标原始出处就标——这是它可被追溯的锚
- **关键数字/强断言**：在正文该处加 `⚠️待核（一手）`
- **回核之后**：在「信源层级」里补 `（✓已核）`

---

## 三、最重要的判定规则

**分水岭不是"一手 vs 二手"，而是"这个判断接下来要承担多大后果"。**

| 用途 | 该用 |
|------|------|
| 存档 / 自己理解 / 分享 | **二手够**（省时间） |
| **做决策 / 对外引用 / 写进方法论** | **必须回一手核对** |
| 一手本身是资产（官方报告/逐字稿） | 标出原始出处，未来能溯源 |

---

## 四、给 Agent 的额外一条（范德 2026-10-05 判断）

**"二手"本质是"人类时间预算"的产物。** 人类没时间看 57 分钟视频，所以需要二手提炼稿。**但对 Agent 体系，这个约束在消失**——处理一手（逐字稿/原始报告）的成本远低于人类。

→ 所以：
- **给"人"看** → 二手（省时间）
- **给"我们的 Agent 体系"用（进记忆/做判断）** → **该直接吃一手**（逐字稿/原始文档），因为一手保留了"为什么"，而"为什么"是判断的原料。

---

## 五、识别"劣质二手"的三个信号

1. **不标出处**——你看不到它转述自哪
2. **不标未知**——把不确定的当确定的说（"已验证""数据显示"）
3. **夹带立场**——文末有推广/导流，结论往产品方向偏

**优质二手长这样**（范本：2026-10-05 Sam Altman/Dot 那篇）：
- 明确标出"公开资料没有 X/Y/Z"（诚实边界）
- 给出原始播客名 + 视频链接（溯源锚）
