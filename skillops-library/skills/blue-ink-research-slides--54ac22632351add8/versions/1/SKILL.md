# 蓝墨研究手绘

从用户提供的五张研究演示参考中提炼视觉语法，用于新内容；不是复刻参考中的人物、品牌、数字或UX主题。参考来源与再分发许可未核实，参考图仅用于本地学习，不自动公开或打包售卖。


## 内容优先的表达构思

先理解内容，再设计讲法，最后应用视觉风格。本节优先于本Skill中的示例布局、默认页型及页数建议；用户明确指定的布局仍应遵守。模板固定视觉语言，不固定故事结构与构图。

生成前先形成一份简短表达简报：听众是谁；希望其理解、感受或采取什么行动；核心主张是什么；必须保留的事实、证据、限制与情绪转折是什么。已有信息足够就直接判断，不机械追问；只有影响讲法的关键缺失才询问。

根据内容选择叙事逻辑：故事按处境、变化、选择与结果推进；观点用依据、例子与成立条件支撑；机制明确参与者、作用和反馈；方法展示任务、操作与关键判断；选择按同维度比较与适用条件展开；文化表达可从生活细节、器物或场景进入。以上是候选讲法，不是另一组强制模板，允许混合或另创。

只有存在实质不同的讲法且用户尚未指定时，提出两种简短方向，解释各自突出什么；普通单页可自主选择，不把每次创作变成审批流程。单页确定表达任务，整套安排进入、推进、转折与停顿，再决定页数、构图、字图比例和视觉节奏。

封面、观点、对比等页型是参考词汇，不是必须凑齐的目录。允许纯文字页、证据页、连续场景或用户内容所需的新页型。不要为了套三步骤而改写过程、为了闭环添加因果、为了风格强放人物或器物；不能用通用口号替代原始细节。插画须解释动作、关系、证据或情绪，否则删掉或改为留白。

验收先看内容：能否说清本页为何采用这个讲法、图像增加了什么理解；原始事实、限定、情绪和关系是否保留；是否因套版发生删减、伪造或过度概括。再检查视觉一致性、文字可读性与尺寸。跨页保持字体、配色、笔触与必要角色一致，布局随内容变化。


## 视觉身份

- 默认极淡冰蓝底#F2F7FF，四边同色；不使用纯白底、米色纸纹、渐变和拟物阴影。黑色主墨、亮蓝约#0667F9、少量浅蓝约#E7F0FF和浅灰。蓝色承载注意力与关系，不铺满背景。
- 黑色轮廓有轻微手绘不规则，但结构清楚；人物头发、裤子、设备可形成小面积纯黑块，和细线界面构成粗细层次。
- 手写标题、数字和批注是视觉组成。中文使用清晰自然的手写黑体/硬笔感，不能机械套英文连笔字，也不用宋体或书法大字。正文简洁、端正、字号足够；标题、正文、边注三级即可。
- 图像主体是可读的证据结构：表格、简化界面、编号流程、任务清单。人物作为观察者、提问者或执行者，通常0—2人，不能遮住信息。
- 蓝色短划、浅蓝胶囊底、圈选和箭头只标关键处；每页1—3个强调焦点。植物、杯子、猫、衣服花纹不是必需元素，默认省略。

## 创作方式

先把内容压成一个主张，再选支持它的证据关系。读[页型与参考](references/page-types.md)，只查看本次相关参考图。用图像工具整页生成文字、插画、结构和留白，不能用HTML排版加一张插画冒充整页成品。

默认横版16:9，最终交付实测1920×1080。左右115px、上下81px内不放必要文字和图形；保留约25%—35%呼吸空间。模型原图尺寸须如实记录，非16:9时等比适配并补白，不拉伸、不裁关键内容。没有图像工具就说明限制，不声称已生成。

图中复杂度默认：一个主结构、最多三个信息组、一句结论。参考里的密集界面不能原样搬入；流程默认3—5步，对比默认2—3对象、最多3指标。资料更多时拆页或征得用户允许增加密度。不给没有来源的评分、数字、参与者属性和业务事实。

生成前把主张、信息组、人物动作、蓝色强调位置和删去的装饰写成简短构图计划，不必停下来等确认。生成后检查中文逐字准确、箭头方向、数据一致性、字体匹配与边距；发现明显问题再修改。

## 验收

1. 远看先读出主张和唯一主结构，近看才出现批注；不是许多等重小卡片。
2. 黑墨+亮蓝、淡蓝底、手写字同时成立；与米色橙色手绘和蓝底工程图可明显区分。
3. 图示说明内容，人物动作有作用；删除装饰后仍能理解关系。
4. 所有结论和比较有用户材料支撑；原参考内容不作为事实沿用。
5. 成品尺寸由工具实测，安全区无关键元素；交付图片、提示词和简短尺寸/校验记录。

只有实际生成并审阅过的页面才能标为完成的页型示例；延伸构图不能伪称已验证模板。


## BR-007 完整套系 v1.1.0

八页型：COVER封面、SECTION章节过渡、CLAIM观点、COMPARE对比、STEPS方法、CYCLE机制、SYSTEM系统、END结尾。方法展示执行路径；机制展示反复起作用的反馈闭环；系统区分角色、工具、输入和输出，不混为一个流程。

角色锚点：研究者为圆黑框眼镜、短卷黑发、浅蓝夹克、深色长裤和白运动鞋；使用者为齐下巴黑短发、白衣蓝袖；协作者为侧分短黑发、无眼镜、白衬衫与深蓝背心。人物是成年人简笔插画，有完整衣着与有意义动作。角色是本套默认叙事身份，不代表特定真人或固定性别职业。封面与结尾沿用同一研究者。

每页按需要使用0—2人，不能为展示角色而重复人物；研究者负责观察与判断，使用者提供真实任务反馈，协作者帮助执行与验证。人物不能遮挡系统关系。标题、标签与说明保持相同的自然硬笔手写字形，仅调字号和字重。

新页面优先查看本套原创示例assets/<页型编号>.jpg（存在时），学习参考references中的旧图仅作辅助。原创示例为生成并人工核对的候选，不代表用户逐页认可。面向公开分发的包仅含原创示例、规则、提示词与规范，不含来源未核实的第三方学习图片。
