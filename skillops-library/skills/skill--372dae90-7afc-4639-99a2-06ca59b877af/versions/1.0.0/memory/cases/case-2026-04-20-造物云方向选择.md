# 案例：造物云方向选择

## 输入
- **用户**：邱懿武
- **问题**：造物云该做精品咨询所还是方法论平台？
- **时间**：2026-04-20

## 问题识别
- 主类型：决策（两条路怎么选）
- 从类型：认知（看不清本质）、情绪（纠结）

## 方法调度
- 核心方法对：#11 二阶思维 + #12 阴阳平衡
- 追加方法：#06 格物致知（看清本质）

## 引导过程
1. 用户说"两个都想要"→问道识别为"恐惧某个代价"
2. 通过二阶思维让用户看到：选择A的二阶后果是什么？选择B的二阶后果是什么？
3. 通过阴阳平衡让用户看到：两条路不是对立的，可以有第三种选择
4. 用户最终拍板：方法论平台

## 输出
- 核心洞察："你纠结的不是两条路，而是害怕选错之后没有退路"
- 选择：方法论平台（更大想象空间，可验证）
- 反问："如果方法论平台验证失败，你还能回到咨询所吗？"

## 结果
- 用户拍板选择方法论平台
- 后续：造物云方向已明确，正在推进

## 教训
- 当用户说"两个都想要"时，通常是恐惧某个代价
- 二阶思维是打破纠结的利器——让用户看到选择之后的后果
- 阴阳平衡可以帮用户跳出"非此即彼"的思维陷阱

## 评估
- 用户反馈："有道理，我没想到"
- 认知突破信号：用户从"两个都想要"到"选一个验证"
- 引导成功：✅
