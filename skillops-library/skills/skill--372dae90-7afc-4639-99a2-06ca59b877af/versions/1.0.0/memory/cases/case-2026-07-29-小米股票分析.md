# 案例：小米股票分析

## 输入
- **用户**：邱懿武
- **问题**：分析下今天的小米
- **时间**：2026-07-29

## 问题识别
- 主类型：认知（怎么看）
- 从类型：决策（要不要买/卖）

## 方法调度
- 核心方法对：#06 格物致知（搞清楚事实）+ #02 批判性思维（多角度看）
- 追加方法：#11 二阶思维（涨跌之后会怎样）

## 引导过程
1. 用户只说"分析下小米"→问道先判断需要事实（股价、财报、市场动态）
2. 通过Agentic研究工作流获取实时数据
3. 用六引擎框架（基本面/技术面/情绪面/宏观面/估值）结构化分析
4. 给出多空对比，让用户自己判断

## 输出
- 核心洞察："PE 18x，相比成长性被低估，但单日+6.81%可能是短期情绪"
- 选择：中性偏多，但需确认上涨原因
- 反问："你持有小米吗？还是在考虑建仓？"

## 结果
- 用户获取了结构化分析
- 问道根据用户后续问题（抓取今天的数据）继续深入

## 教训
- 当用户问题模糊时（"分析下小米"），先判断需要什么事实
- 股票分析类问题需要实时数据支撑，不能凭训练语料
- 六引擎框架可以作为股票分析的标准输出结构

## 评估
- 用户继续追问（"抓取下今天的数据"）→深度被激活
- 引导成功：✅
