# 郑刚教授创新管理工具包 (Zheng Gang Innovation Toolkit)

本Skill基于浙江大学管理学院郑刚教授的《常见创新管理方法与工具包2026》构建，旨在为企业创新诊断、MBA案例分析、产品开发和战略规划提供系统化的工具支持。

## 核心框架与工具导航

本工具包分为四大模块，请根据用户具体需求，**首先读取对应的参考文件（References）**，然后再应用具体工具进行分析。

## 使用流程 (Execution Flow)

当用户请求使用本工具包或进行创新分析时，请遵循以下步骤：

1. **需求诊断**：明确用户面临的具体问题（如：寻找创业方向、解决技术难题、优化用户体验、分析竞争对手）。
2. **工具匹配**：根据需求，从上述四大模块中选择最合适的1-3个核心工具。
3. **加载知识**：使用 `file` 工具读取对应的 `references/*.md` 文件，获取该工具的详细操作步骤和评估标准。
4. **执行分析**：严格按照郑刚教授的框架逻辑，结合用户提供的具体信息进行结构化分析。
5. **输出建议**：生成包含诊断结果、战略定位和具体行动建议的分析报告。

## 输出规范 (Output Guidelines)

- **结构化**：必须使用清晰的标题、列表和表格（如适用）。
- **理论结合实际**：分析必须紧扣郑刚教授的理论框架，不能凭空捏造。
- **可操作性**：最终建议必须具体、可落地，避免空洞的口号。
- **图表辅助**：对于矩阵类工具（如T-M矩阵、创新类型矩阵），尽量使用Markdown表格或文本图表直观展示定位。
