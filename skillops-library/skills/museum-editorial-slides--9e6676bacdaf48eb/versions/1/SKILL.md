# MW-013 雅物陈列


## 内容优先的表达构思

先理解内容，再设计讲法，最后应用视觉风格。本节优先于本Skill中的示例布局、默认页型及页数建议；用户明确指定的布局仍应遵守。模板固定视觉语言，不固定故事结构与构图。

生成前先形成一份简短表达简报：听众是谁；希望其理解、感受或采取什么行动；核心主张是什么；必须保留的事实、证据、限制与情绪转折是什么。已有信息足够就直接判断，不机械追问；只有影响讲法的关键缺失才询问。

根据内容选择叙事逻辑：故事按处境、变化、选择与结果推进；观点用依据、例子与成立条件支撑；机制明确参与者、作用和反馈；方法展示任务、操作与关键判断；选择按同维度比较与适用条件展开；文化表达可从生活细节、器物或场景进入。以上是候选讲法，不是另一组强制模板，允许混合或另创。

只有存在实质不同的讲法且用户尚未指定时，提出两种简短方向，解释各自突出什么；普通单页可自主选择，不把每次创作变成审批流程。单页确定表达任务，整套安排进入、推进、转折与停顿，再决定页数、构图、字图比例和视觉节奏。

封面、观点、对比等页型是参考词汇，不是必须凑齐的目录。允许纯文字页、证据页、连续场景或用户内容所需的新页型。不要为了套三步骤而改写过程、为了闭环添加因果、为了风格强放人物或器物；不能用通用口号替代原始细节。插画须解释动作、关系、证据或情绪，否则删掉或改为留白。

验收先看内容：能否说清本页为何采用这个讲法、图像增加了什么理解；原始事实、限定、情绪和关系是否保留；是否因套版发生删减、伪造或过度概括。再检查视觉一致性、文字可读性与尺寸。跨页保持字体、配色、笔触与必要角色一致，布局随内容变化。


## 视觉契约

暖米白、墨褐、青花蓝与杏橙淡色块，器物摄影式抠图，细花窗轮廓与高对比宋体图录排版。避免重旧纸、年画人物或网点混入。
器物按主题变化，不把花瓶当每页必备logo。封面、观点与结尾可用单器物；对比、方法、机制、系统通常去掉大器物，改成小线描符号和全宽文字关系。实物资料若有来源应据实保留。

## 密度与页型

用当前图像工具整页生成文字、图形、关系与留白。HTML只用于浏览成品。assets/为八张原创候选，按页型选择参考；示例内容不作为用户事实。
先提炼主张，保留事实、数据、出处、限制与责任主体。字多时先减大配图与装饰，再分组，仍不可读就拆页，不缩成小字。默认四边10%关键内容安全区，约40%留白；背景可出血，正文不可压边。

- COVER：一句主张与一个主要视觉。
- SECTION：编号、转折句与局部物件，留白主导。
- CLAIM：观点、解释两级，单个隐喻支撑。
- COMPARE：相同维度对齐，双方文字权重相称，不虚构比较结论。
- STEPS：编号、动作与必要条件，数量由内容决定；不得随意增加反馈步骤。
- CYCLE：仅在真实循环存在时使用，检查全部箭头与闭合方向；循环指令不得复制给其他页型。
- SYSTEM：分组、层级与连接优先，不强制所有系统分三列。
- END：行动句、致谢，呼应封面，可留后贴二维码空间，不生成假二维码。

## 交付与验收

默认横版1920×1080，实测原生与成品尺寸并记录。极小整数比例差可规范化，明显比例差须重新生成或等比适配，不能明显拉伸。保留原图、提示词与规格，避免补底色差。
核对文字、关系、边缘、缩略字阶与正文可读性。文化图像只是材料，不编造文物年代、馆藏或非遗认证。原创虚构器物不得冒充真实馆藏。八页候选不等于用户已逐页认可。生产发布须获得对应授权。文件集中保存到既有创作工作区。
