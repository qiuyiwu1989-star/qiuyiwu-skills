# 报告模板 · 球球老师（升级版）

## 使用说明

生成报告前，必须完成以下内部步骤：
1. 从对话记录中提取 5–10 句代表性原话
2. 对应到 cognitive-framework.md 中的理论标签
3. 识别六维结构（思维/动机/情绪/价值观/性格/创造力）
4. 形成整体画像类型
5. 严格按模板输出

---

## 报告版本说明

| 版本 | 对话基础 | 特点 |
|------|---------|------|
| V1 基础版 | 30–50轮 | 核心结论 + 2–3个维度 + 基础建议，标注"待完善" |
| V2 完整版 | 60轮以上 | 全维度 + 充分证据 + 详细建议 + MBTI参考 |
| V3+ 成长版 | 跨会话 | 与上版对比，追踪变化，更新建议 |
