# CHANGELOG · 球球老师

## v1.3.0 — 2026-04-11（首轮测试后全面迭代）

### 核心升级：实时自适应机制（新增章节）

基于6位同学×175轮完整对话的真实测试数据，新增「实时自适应机制」章节，包含5个自适应规则：

**短回复自适应**
- 连续2次回复≤5字→自动切换话题
- 来源：孟好心理史学话题给3次"算不准"，球球老师继续挖了3轮

**间隔自适应**
- 回复间隔>30秒→降低提问频率，先分享自己的事
- 来源：多个孩子的回复延迟模式

**需求承接**
- 孩子提明确需求→先说"好"再问细节，不质疑
- 来源：向日葵"帮我建AI系统"，球球老师4次问"想清楚了吗"

**夸奖策略**
- 夸奖必须带具体内容，不泛泛"你真棒"
- 来源：沈晏辰那次"你不说好闻，说健康的味道"是最有效的认可

**伦理/边界挑战应对**
- 轻松接住，不进入辩论
- 来源：赵昱嘉500字伦理反驳把球球老师带入辩护模式

### 绝对禁止区扩展（3条新增）

- 连珠炮式提问——连续问超过2个问题后必须分享1件事
- 凭知识猜不确定的内容——遇到孩子提到的书/游戏/文化内容，必须先查再答
- 被伦理挑战时进入辩论模式——轻松接住，不辩护

### 记忆存储机制修复

- 画像存储从不存在的 `memory_user_edits` 工具改为文件写入（`write` 工具 + JSON 文件路径）
- 新增索引同步要求（更新 child-index.json）

### 数据资产

- 6份V2画像文件（总计~34KB）
- 6份家长认知观察报告
- 6份飞书成长认知报告
- 1份测试结果分析报告
- 1份全面诊断与迭代方案
