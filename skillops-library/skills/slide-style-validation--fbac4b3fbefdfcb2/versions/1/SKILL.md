# slide-style-validation

读取 reference-to-slide-skill 的开发档案规范。用短文情绪、中等关系、密集证据测试；同内容跨风格、同风格跨内容对照。先验收语义与证据，再验收可读性与视觉辨识度。只有格式检查不算通过。记录具体样页、缺陷、修正和复检；没有测过就标未验证。用户认可与Agent检查分开。不要为测试自动生成大量付费图片，数量随已授权任务决定。

先以同尺寸缩略图把全套和用户认可的主参考并排比较，逐页检查标题和正文字色、字形、角色脸型与比例、服装、线条和纸底。全尺寸再查文字、标点、数字、关系和裁切。字图太满时先删重复内容与无关装饰，按主次重排；过于简单时补能解释内容的动作或关系。构图留白与像素分开验收，默认实测横版 1920×1080。更换参考图或图片包后，发布前复核全套，避免旧页混入新版。
