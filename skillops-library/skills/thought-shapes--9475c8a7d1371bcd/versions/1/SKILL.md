# 思想的形状

让看不见的思考，在疏密、虚实与流动之间显形。

## 内容先于风格

先读项目简介、文章论点或用户提供的材料，提炼一个主要关系或动作，例如跨情境延续、证据追溯、不同主体共创。把它转成具体构图，不能只把项目名交给生成器猜测。资料不足时采用保守隐喻并标注推断，不凭名称编造功能。

用户可以指定风格、混合风格或授权你决定。八种基础风格都是可选项，不默认收窄为一种；读 [八种风格](references/styles.md)，按内容和使用尺寸选择。色彩、线条、材质、留白比例可分别调整，保持项目身份而非一键换色。

## 共同视觉约束

- 宋式气质来自清润色彩、疏朗比例、虚实、精致材质与非对称平衡。避免用山水、竹、鹤、印章堆出“中式”。
- 高级灰是低饱和多色体系：青瓷灰、月白、藕灰、茶灰、淡赭、适量墨色。局部需要足够对比，不能全部淡到看不清。
- 每张一个视觉重心和一个主要关系。避免通用波浪、随意圆球、重复三色背景。纹理细而克制，不做旧发黄。
- 网站图片默认无字，标题交给页面。展示板可在图外加编号与标题。
- 产品卡片默认横版 3:2；按实际容器重新构图或明确裁切安全区，不把比例写成通用硬约束。
- 用户照片双联海报是独立模式：每张照片独立处理，上半原照保真，下半转译；默认3:4上下均分，仅在用户请求此模式时使用。

## 生成与交付

使用可用的图像生成工具；在当前 Codex 环境遵循 imagegen 技能。独立资产逐张生成，不用一张拼版裁切冒充独立生成。多图可分小批处理，维护可恢复清单。工具不可用时明确说明，不悄悄改成未经授权的付费 API。

批量任务先清点产品与仓库、去重同一实体；插件和客户端有不同用途时保留独立配图，家族色彩可关联。公开仓库不自动等于具有开源许可证。

清单记录：id、来源说明、产品/仓库别名、风格、隐喻、完整提示词、输出路径、生成状态、审阅状态。不要把生成成功写成用户认可。原图放项目资产目录，网页另存压缩版本；记录生成器原始路径用于追溯。

制作可按名称和风格浏览的审阅页，显示图片、风格、简短内涵和项目入口。逐张检查原图/缩略图；网页检查图片是否加载、裁切、移动端、搜索与空结果。优先修复错义、乱码、风格偏离、无辨识度、断图。技术验证不代替审美确认。

风格规则、批量落地经验见 [案例与检查](references/case-study.md)。新任务复用方法与样例，不把旧项目清单当成永远不变的事实。网站发布、推送或批量替换线上资产仍需对应授权。

## 模板与风格调用
执行前按用途读取 [提示词调用目录](references/prompt-catalog.md)。先选模板ID，再选风格ID，最后指定配色、尺寸与笔触参数；模板输入不足时不要编造来源。目录包含适用条件、完整提示词及尚未试样的候选方向。
