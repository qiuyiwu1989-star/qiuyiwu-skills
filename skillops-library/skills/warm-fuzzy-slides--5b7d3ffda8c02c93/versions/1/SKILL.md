# 暖绒日常

## 使用与状态
本套为原创八页试用模板，尚未经用户逐页确认和密集证据页压力验证。不要把参考构图当固定套版，不自动发布到网站。

## 视觉语言
暖奶油底、雾蓝针织与橘色毛绒、细颗粒粉彩质感。橘白猫、雾蓝毛衣为可选角色锚点；猫的眼神和动作要有变化。标题圆润厚实，正文清晰深棕，不用细淡字。肌理集中在插画，正文区平静。不切换到厚涂写实油画。

## 内容驱动
先确定听众、本页主张和需要解释的关系。插画必须帮助理解动作或情绪；没有作用就删。短观点用一个动作与大留白；中量文字减少角色、放大关系；长文先保留事实和限制，再删装饰与配图，仍放不下就拆页，不能缩字硬塞或省略依据。

## 页面参考
assets/COVER.jpg、SECTION.jpg、CLAIM.jpg、COMPARE.jpg、STEPS.jpg、CYCLE.jpg、SYSTEM.jpg、END.jpg 分别对应封面、章节、观点、对比、方法、机制、系统、结尾。根据语义取用参考；允许纯文字、证据页、新构图。对比需同维度；方法保留真实步骤；机制仅在真实存在回路时画闭环；系统要说明并列、依赖或反馈，不能为了好看添加箭头。结尾呼应开场但改变动作与尺度。

## 整页生成与尺寸
用图像工具同时生成文字、插画与留白，不以HTML占位图替代。需要角色一致时传入本套原创页作为参考。横版16:9，交付1920×1080，记录原生像素与适配像素。文字和关键对象四周至少8%安全区，优先35%以上空白。校核实际尺寸，不把提示词尺寸当结果。只对几乎16:9的原图做微小整数适配；明显不符时重新生成或等比适配，不拉伸。

## 验收
逐字核对标点、数字、限定；不要在已带句号的文案后再次拼句号。检查箭头方向和完整闭合，检查多组并列是否被错误画成因果。查看缩略图的阅读顺序与全尺寸的文字。减少装饰胜过缩小文字。新内容必须重新设计，不机械复用本套成长主题。不同内容适用性目前是建议，不是已验证事实。
