# CS-009 高彩贴纸涂鸦

用图像工具共同生成文字、图形、关系与留白。先理解页意，再选择构图。用户已选择去掉人物：不放真人照片、头像、人形或身体局部；用纸片、电话、铅笔、喇叭与抽象符号讲内容。


## 内容优先的表达构思

先理解内容，再设计讲法，最后应用视觉风格。本节优先于本Skill中的示例布局、默认页型及页数建议；用户明确指定的布局仍应遵守。模板固定视觉语言，不固定故事结构与构图。

生成前先形成一份简短表达简报：听众是谁；希望其理解、感受或采取什么行动；核心主张是什么；必须保留的事实、证据、限制与情绪转折是什么。已有信息足够就直接判断，不机械追问；只有影响讲法的关键缺失才询问。

根据内容选择叙事逻辑：故事按处境、变化、选择与结果推进；观点用依据、例子与成立条件支撑；机制明确参与者、作用和反馈；方法展示任务、操作与关键判断；选择按同维度比较与适用条件展开；文化表达可从生活细节、器物或场景进入。以上是候选讲法，不是另一组强制模板，允许混合或另创。

只有存在实质不同的讲法且用户尚未指定时，提出两种简短方向，解释各自突出什么；普通单页可自主选择，不把每次创作变成审批流程。单页确定表达任务，整套安排进入、推进、转折与停顿，再决定页数、构图、字图比例和视觉节奏。

封面、观点、对比等页型是参考词汇，不是必须凑齐的目录。允许纯文字页、证据页、连续场景或用户内容所需的新页型。不要为了套三步骤而改写过程、为了闭环添加因果、为了风格强放人物或器物；不能用通用口号替代原始细节。插画须解释动作、关系、证据或情绪，否则删掉或改为留白。

验收先看内容：能否说清本页为何采用这个讲法、图像增加了什么理解；原始事实、限定、情绪和关系是否保留；是否因套版发生删减、伪造或过度概括。再检查视觉一致性、文字可读性与尺寸。跨页保持字体、配色、笔触与必要角色一致，布局随内容变化。


## 视觉契约

- 钴蓝 #123DEA、明黄 #FFD629、朱红 #FF4227、黑与暖白。每页一个主色，其余作强调；允许白、蓝、黄底交替形成节奏，不能每页所有颜色平分面积。
- 粗黑有机线条、轻微纸张纹理、剪贴白边、少量胶带。标题是有力量且可读的手写黑体，正文清晰无衬线。避免廉价彩虹字和密集漫画杂物。
- 每页一个视觉重点，通常一个主要物件，最多三个辅助装饰点。关系箭头必须帮助理解，不能为热闹随意连接。
- 四周安全区默认宽高的9%，目标约35%空白。装饰可少量越界，正文和标题不能越界。用户明确修改时以新要求为准。

## 文字密度与页型

先区分主张、解释、事实和限制。保留事实、数字与限定；删除重复。文字增加时，先减装饰和主物件，再调整布局；仍不可读就拆页，不能缩成小字或静默删掉条件。

- COVER：一个短主张、一个物件。正文少，视觉强。
- SECTION：章节编号与转折句，留大量空白。
- CLAIM：一句观点加解释，以物件隐喻支撑。
- COMPARE：两个明确比较对象，相同维度逐项对齐；不虚构比较数据。
- STEPS：通常三个步骤，每步动作与必要说明；文字中等时只留小图标。
- CYCLE：节点与方向清晰，确认真的是循环，避免装饰箭头造成错误因果。
- SYSTEM：用分组、层级与连接表达规则，文字占主位；不强塞复杂系统进三列。
- END：短行动句与致谢，预留后贴二维码的位置，不生成假二维码。

八张原创候选见 assets/，按页型选择相关一张作为视觉参考。示例文字只是排版素材，不作为用户事实；不要照搬示例标题到所有项目。

## 生成与验收

提示词包含页意、准确上屏文字、布局、色彩、无人物、安全区。使用当前图像工具，无能力时明确说明，不能用HTML占位冒充整页生成。

默认交付横版1920×1080，实测像素，分别记录原生和交付尺寸。原生仅有整数比例误差时可微量规范化；明显不同比例须重新生成或等比适配，不能强拉伸。不要给实色图加不同颜色的补边。

逐字检查标题与正文、箭头关系、无人物、边距及远看可读性。八张候选已生成不等于用户已逐页批准。只有获得对应发布授权后才上传生产环境。
