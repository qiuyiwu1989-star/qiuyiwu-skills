# 听众透镜（Stakeholder Lens）

同一产品，不同听众要完成的"任务"不同。写故事前先查本表，选对场景和痛点。表内以教育场景为主，其他行业可按"他要对谁交代 / 他怕什么 / 他拿什么证明自己做对了"三问自行推导。

| 听众 | 他真正要完成的任务 | 典型顾虑 | 有效的"场" | 有效的"证" | "邀"的形式 |
|---|---|---|---|---|---|
| 家长（2–10 岁） | 孩子不在身边时也能知道他好不好、该怎么陪 | 隐私、孩子被同学/老师另眼看待、内容重复无新意、价格 | 入托/入学第一周、孩子突然情绪异常、老人/育儿嫂带娃理念不同 | 一份真实的孩子日报/多视角报告；其他家长原话 | 试用 1–2 周；按月服务费 |
| 特殊儿童家长 | 获得客观证据、找到干预方向、说服家人与学校 | 被贴标签、费用高、不知道找谁 | 老师又来找你说孩子在学校的问题，但你不知道到底发生了什么 | 多视角报告让外婆放心、年级组长转支持的前后对比 | 先出一份评估报告 |
| 一线老师 | 减负、出成果（课题/论文/评优）、处理家长沟通 | 被监控、增加工作量、成果归领导 | 期末要交课题却没数据；家长不认可你对孩子的判断 | 自动生成的评课/选题报告；成果署名、skill 软著与版权分成 | 先帮你做一门课/一个课题 |
| 校长 | 出办学特色与成绩、对上级有交代、安全不出事 | 学生分心（平板之痛）、隐私舆情、预算与流程 | 评价改革要求过程性数据而学校拿不出；兄弟学校已经有成果 | 标杆校视频/样板账号；可被上级看到的成果 | 一个班试点；20 万以下校长可拍板的打包价 |
| 教育局/区域 | 政策落地（评价改革、托育、AI+教育）、可复制样板 | 合规、公平、招投标 | 新政策要求 X 但区域缺抓手 | 试点校数据、课题背书（高校教授） | 区域课题合作 |
| 托育/幼儿园园长 | 托幼一体化等政策课题、家园共育、减少家长投诉 | 安全、隐私、老师抵触 | 新生入园分离焦虑期、家长质疑"孩子在园被欺负" | 教授课题背书、多园联合研究 | 课题制试点 |
| 投资人/合作方 | 判断市场规模与可复制性 | 是不是又一个录音笔 | 一个细分场景的单点突破故事 | 种子用户付费与复购、交付物质量稳定性 | 下一阶段里程碑 |

## 使用方法
1. 找到听众所在行，抄下"任务"作为故事的北极星。
2. "场"从本行挑一个，或用"转折时刻"法自造：**变化前 → 变化发生 → 他突然失去了什么信息/控制感**。
3. 把对应"顾虑"提前编入"解"（例如：先讲"只录自家孩子、家长授权、他人声音过滤"），不要等对方问。
4. "证"按本行列出的证据类型准备，没有就标注为【待补证据】并建议如何获取（找种子用户）。
