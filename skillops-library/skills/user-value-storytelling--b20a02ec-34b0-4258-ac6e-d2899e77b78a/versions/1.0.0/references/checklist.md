# 叙事自检清单（10 项，每项 0/1/2 分，满分 20）

| # | 检查项 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|---|
| 1 | 开场无产品 | 前 3 句无产品名/设备/系统/平台 | 第 2–3 句出现 | 第 1 句就是产品 |
| 2 | 是时刻不是标签 | 具体转折时刻、第二人称画面 | 场景较泛 | 人群标签或无场景 |
| 3 | 痛有代价 | 情绪 + 后果 + 现有方案为何不够 | 只有情绪或只有后果 | 抽象收益（"提升效率"） |
| 4 | 雪中送炭 | 主线需求属必备/期望型（拿走会难受） | 主线不清 | 主线是兴奋型/锦上添花 |
| 5 | 设备被逻辑带出 | 按"痛→AI→AI需要X→设备"推出 | 跳跃但能理解 | 直接讲硬件 |
| 6 | 用对方的词 | 无术语 | 少量术语已解释 | 大量技术术语/流程 |
| 7 | 证据可见 | 有交付物样例或真实用户故事 | 只有数据 | 只有功能描述 |
| 8 | 顾虑前置 | 主动化解该听众核心顾虑（隐私/监控/预算） | 被问才答 | 未涉及 |
| 9 | 邀请低门槛 | 具体、可试用、价格锚定痛的代价 | 有邀请但模糊 | 无邀请或按成本报价 |
| 10 | 聚焦 | 一个主场景 + 少量加码 | 2–3 个场景并列 | 功能清单式铺开 |

**判定**：≥16 可直接用；12–15 修改标 0/1 分项；<12 回到"场"和"痛"重写。

**复盘时的听众反应信号**
| 信号 | 说明哪一步失效 |
|---|---|
| "跟 XX 有什么区别？" | 场/痛不够，过早暴露产品品类 |
| "多少钱？"（太早出现） | 痛的代价没建立，只能比价 |
| 举手质疑"能带进去吗/隐私呢" | 顾虑未前置 |
| 沉默、转移话题 | 场景不共鸣（标签式） |
| "你居然可以！" / "这怎么做的？" | 证据生效，可进入邀 |
