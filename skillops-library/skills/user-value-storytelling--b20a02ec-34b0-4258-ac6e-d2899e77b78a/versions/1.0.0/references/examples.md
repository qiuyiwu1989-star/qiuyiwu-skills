# 实战改写案例

## 案例 1：录音胸牌 · 家长线

**改写前（产品思维）**
> "我们做了一款基于录音设备的应用，针对双职工家庭。孩子戴上设备记录日常对话，经过 AI 梳理成片段、总结分析，生成报告给家长，首页有 IP 形象和心情分，还能生成亲子绘本。"

问题诊断：
- 开场即"录音设备"→ 激活比较，触发"能带进校门吗？"的质疑
- "双职工家庭"是标签，不是时刻 → 不引共鸣
- 讲处理流程（梳理→总结→分析）→ 听众被拉进我们的视角
- 绘本是兴奋型需求，被放在主线 → 锦上添花

**改写后（五步）**
- **场**：孩子第一天上托班。早上你把他交给老师，门一关——接下来 8 个小时，你什么都不知道。
- **痛**：晚上接他，问"今天开心吗"，他说"开心"，或者什么都不说。可他这周哭了三次，你不知道为什么。你不知道该安慰、该追问，还是该去找老师。
- **解**：如果有一位一直陪在他身边的"AI 小伙伴"，能听到他这一天说了什么、跟谁玩、什么时候不开心，晚上告诉你：今天发生了这 3 件重要的事，今晚你可以这样陪他——这需要 AI 有一只"耳朵"，就是孩子胸前这张小卡片。
- **证**：（展示一份真实日报）"这是 X 妈妈孩子入托第 3 天的报告……她说看完那天晚上第一次没有焦虑。"惊喜加码：还能把这一天变成一本以孩子为主角的绘本。
- **邀**：先试两周，陪孩子度过适应期。按月服务费，比一次早期干预评估便宜得多。

## 案例 2：录音胸牌 · 学校线（面对校长）

**改写前**："我们有老师胸牌和学生小白屏，课堂全程录音，自动生成课堂报告，做一人一档。"→ 校长："这跟钉钉有什么区别？"

**改写后**
- **场**：评价改革下来了，上级要过程性数据，要特色成果。学校每个老师都很忙，期末一看——课题没数据，论文没素材。
- **痛**：钉钉也录了很多会议、很多课，但录完就躺在那里，没人知道怎么用。数据有了，成果没有。
- **解**：让 AI 每天替老师把课堂"听一遍"，自动找出这堂课的亮点、学生的变化、可以写成课题的选题，每天推给老师。老师只需判断"对不对"。
- **证**：春芽学校的样板账号与视频；某老师用它完成的一个选题。
- **邀**：先在一个班试点一个学期；整校方案控制在校长可拍板的预算内。
- **被问"和钉钉区别"时（错位竞争）**：4G 无感直传到学校组织，不用老师手动导；钉钉给的是纪要，我们给的是每天推送的下一步应用。

## 案例 3：美容院（跨行业）
- **场**：店里最好的那个顾问要离职了。
- **痛**：她的成交话术都在她脑子里，新人上手要三个月，这三个月的业绩谁来补？
- **解**：让 AI 听金牌顾问的真实对话，把话术沉淀进库，新人随时调用、AI 实时提醒。
- **证**：老板一听就说"有道理"——话术库样例。
- **邀**：先给一位金牌顾问戴一个月。

## 共同规律
1. 开场是一个**时刻**，不是一个人群或一个产品。
2. "痛"里都有一个**信息断层**（不知道孩子发生了什么 / 不知道数据怎么用 / 经验在人脑里带不走）——这正是"AI 的耳朵"的价值落点。
3. 设备在"解"的后半句才出现，且以"AI 需要它"的身份出现。
