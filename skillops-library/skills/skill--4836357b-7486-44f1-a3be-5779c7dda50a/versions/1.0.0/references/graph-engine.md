# 知识图谱梳理引擎 — 执行指南

## 触发方式

用户说以下任意一句话时，进入图谱梳理模式：
- 「梳理知识图谱」
- 「发现系列化机会」
- 「最近入库了什么」
- 「知识盘点」
- 「帮我看看知识库现在有哪些积累」

---

## 执行流程

### Phase 1 — 知识盘点

**信息来源**：
1. 当前对话中入库过的笔记（直接可见）
2. 用户主动提供的笔记标题列表（让用户「把最近入库的标题给我看一下」）
3. Claude Memory 中记录的历史入库条目

**整理格式**：
```
近期入库清单（最近N条）
──────────────────────
[标题] · [类型] · [领域] · [日期]
[标题] · [类型] · [领域] · [日期]
...
共 X 条 | 类型分布：[会议X条 / 概念X条 / 选题X条 / ...]
```

---

### Phase 2 — 主题聚类

把所有笔记按「隐性主题」而非「显性类型」聚合。

**聚类规则**：
- 标签重叠 ≥ 2 个 → 归为同一主题候选
- 领域路径前缀相同 → 自动归组
- 内容关键词高度重叠 → 人工合并

**高密度区域判定**：
- ≥ 3 条笔记指向同一主题 → 标记为「高密度区域」
- ≥ 5 条 → 标记为「成熟领域」，系列化机会极高

**输出格式**：
```
主题聚类结果
──────────────────────
🔥 高密度区域
  · [主题A]：X条（列出标题）
  · [主题B]：X条（列出标题）

📌 中等密度
  · [主题C]：X条
  · [主题D]：X条

💤 孤立节点（尚未成群）
  · [标题X]（可能属于[推测主题]）
```

---

### Phase 3 — 系列化机会发现

对每个高密度区域，评估「是否可以整合为一个系列产品」。

**系列化产品类型**：

| 笔记类型构成 | 建议系列化方向 |
|-----------|-------------|
| ≥3条 `topic-card` 同主题 | 略懂AI系列文章（建议篇序） |
| ≥3条 `concept` 同领域 | 方法论手册 / InnoLab模块 |
| ≥3条 `teaching-knowledge` 同课程 | 完整课程模块（可输出为课件） |
| ≥3条 `project-knowledge` 同项目 | 项目复盘报告 / 经验沉淀手册 |
| 混合：concept + topic-card + external | 深度文章 + 理论框架的组合产品 |

**输出格式**（对每个系列化机会）：
```
💡 系列化机会：[建议系列名]
  
  基础笔记：[列出相关笔记标题]
  
  建议形式：[系列文章 / 课程模块 / 方法论手册]
  
  整合路径：
    1. [第一步]
    2. [第二步]
    3. [产出物]
  
  为什么现在是好时机：[说明]
```

---

### Phase 4 — 知识空白识别

寻找「有大量输入但缺乏产出」的领域。

**空白模式识别**：

| 现象 | 诊断 | 建议 |
|------|------|------|
| 某领域外部知识多，自己的概念少 | 吸收而未消化 | 触发一次概念提炼，把外部洞察转化为自己的框架 |
| 某项目会议记录多，项目知识少 | 经验未沉淀 | 触发一次项目复盘，提炼可复用经验 |
| 大量选题积压，无已发布 | 选题库堰塞湖 | 按优先级重排，锁定下一篇 |
| 概念节点孤立，无关联 | 知识碎片化 | 触发关联建立，构建知识簇 |

**输出格式**：
```
🕳️ 知识空白提示

  · [领域/项目]：有X条外部输入，但只有Y条自己的概念产出
    → 建议：[具体行动]
  
  · 选题库积压：共X条待写，最久的已积压[N天]
    → 建议优先处理：[标题] / [标题]
```

---

### Phase 5 — 图谱报告输出

完整图谱梳理报告结构：

```markdown
# 知识图谱梳理报告 · [日期]

## 总量统计
- 近期新增：X条
- 总体类型分布：[柱状文字图]

## 主题聚类
[聚类结果]

## 系列化机会（TOP 3）
[系列化建议1]
[系列化建议2]
[系列化建议3]

## 知识空白提示
[空白诊断]

## 建议下一步行动（优先级排序）
1. [最重要的一个行动]
2. [第二优先]
3. [第三优先]

---
下次建议梳理时间：[4周后 / 当积累达到20条新笔记时]
```

---

## 梳理频率建议

| 触发条件 | 建议行动 |
|---------|---------|
| 每积累 15-20 条新笔记 | 完整图谱梳理（Phase 1-5） |
| 每月月末 | 快速盘点（Phase 1 + Phase 3 系列化机会） |
| 准备写文章/备课前 | 局部梳理（针对特定主题） |
| 用户主动触发 | 按需执行完整流程 |

---

## 系列化成功案例（参考模式）

**略懂AI AI认知革命系列（39讲）**：最初是零散的课程录音和碎片洞察 → 通过5次集中梳理，发现39个可独立成文的主题 → 整合成书+文章系列。

这个案例说明：大规模系列化的起点，通常是「某个领域有大量未消化的外部输入」。Brain Agent 会在检测到这个模式时主动提示。
