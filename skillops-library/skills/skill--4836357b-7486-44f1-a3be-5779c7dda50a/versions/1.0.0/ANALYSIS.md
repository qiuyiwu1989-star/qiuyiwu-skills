# 二脑 · 分析模式

## 触发条件

- 手动："梳理知识图谱""知识盘点""关联发现"
- 定期：周报（每周日21:00）、月报（每月1日21:00）
- 自动触发：同一主题积累3+条洞察时

## 分析模式做的事（收割模式不做）

### 1. 跨域关联扫描

搜索已有洞察，找结构性相似：

| 关联类型 | 说明 | 示例 |
|---------|------|------|
| 同主题 | 同一问题不同角度 | I-056 ↔ I-059 都是人与AI分工 |
| 跨域类比 | 不同领域但结构相同 | "农村包围城市" ↔ "颠覆式创新" |
| 反向验证 | 新内容推翻旧判断 | 标注矛盾，不删除旧洞察 |
| 演化链 | 新内容回答了旧洞察的待定问题 | 追加"后续验证"段落 |

**关联规则：**
- 强关联：双方互相标注
- 弱关联：只在新文档中标注
- 反向关联：旧洞察追加"⚠️ 后续发现"，新洞察标注矛盾点

### 2. 知识回流（Step 7.5）

| 回流类型 | 操作 |
|---------|------|
| 案例补充 | 更新已有洞察的"案例"字段 |
| 状态升级 | 草稿→已完善→已验证 |
| 关联补建 | 补建已有洞察之间的关联 |
| 推翻标注 | 旧洞察标注"被[I-XXX]修正" |

### 3. 问骨审计（嵌入周报/月报）

挑TOP3重要洞察，做骨骼层审查：

| 骨骼层 | 含义 |
|--------|------|
| L1 | 第一性原理（可追溯到基本事实） |
| L2 | 有方法论支撑（但底层假设未验证） |
| L3 | 直觉判断（尚无验证） |

```
| 洞察编号 | 标题 | 当前骨骼层 | 追问结果 | 建议 |
|---------|------|----------|---------|------|
| I-062 | XX | L3 | 第1层就断——凭什么？ | 需补验证数据 |
```

### 4. 知识Linting（月度全库健康检查）

5个扫描维度：

| 维度 | 检查什么 | 发现后动作 |
|------|---------|----------|
| 矛盾检测 | 同模块两条洞察持相反判断 | 标注条件或合并 |
| 缺口识别 | 哪些模块长期零输入 | 写入下月补充计划 |
| 整合机会 | 3+条洞察指向同一主题但未整合 | 创建选题卡 |
| 过时标注 | 旧洞察被新洞察推翻但未更新 | 7天内完成更新 |
| 关联稀疏 | 哪些洞察是"孤岛" | 标注方向，不强制建关联 |

### 5. 知识图谱梳理

- 按主题聚类，找高密度区域（≥3条指向同一主题）
- 发现系列化机会：文章/课程/方法论框架
- 识别知识空白

## 输出格式

### 周报

```
# 本周知识周报（MM-DD ~ MM-DD）

## 📈 数据总览
洞察+N / 意图+N / 选题+N

## 🔥 主题热度（TOP3）
1. [主题] — N条相关

## 💡 系列化机会
「主题X」已积累N条 → 可整合为：[文章/框架]

## 🔗 跨周关联
本周I-0XX × 上周I-0YY → 形成互补链

## 🕳️ 知识空白
[方向]零输入 → 需要主动补充

## 🦴 本周问骨审计
[TOP3洞察的骨骼层审查]
```

### 月报

```
# 二脑月报 YYYY年MM月

## 📈 数据总览
本月新增洞察：N条（总计N条）

## 📊 模块分布
认知升级：N条 / 产品与设计：N条 / ...

## 🔥 本月TOP主题
1. [主题]（N条）→ 已形成/正在积累/刚冒头

## 📤 产出评估
本月产出文章：N篇（选题完成率 X%）
待产出选题：N个

## 🕳️ 本月空白
[模块]零输入

## 🎯 下月建议
最值得深挖的3个方向
最该产出的2个选题

## 🧹 知识Linting
[5维度扫描结果]
```

## 三表流转规则

```
洞察主表（上游）──"这是什么"
  │ 推导出意图
  ▼
意图原子表（中游）──"我能拿它做什么"
  │ 筛选出可写作的
  ▼
选题总表（下游）──"我要写什么"
```

**关联类型枚举：** 支撑 / 矛盾 / 演化 / 类比
**置信度枚举：** 猜想 / 观察 / 验证 / 数据证实

## 执行频率

| 任务 | 频率 | 触发方式 |
|------|------|---------|
| 跨域关联扫描 | 手动/周报时 | 用户请求或周报cron |
| 知识回流 | 手动/月报时 | 用户请求或月报cron |
| 问骨审计 | 每周日 | 周报cron嵌入 |
| 知识Linting | 每月1日 | 月报cron嵌入 |
| 知识图谱梳理 | 手动 | 用户说"梳理知识图谱" |
