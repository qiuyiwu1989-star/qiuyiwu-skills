# 三表定义 — 洞察主表 × 意图原子表 × 选题总表

## 核心原则

**三张表的区别不是"内容是什么"，而是"我拿它干什么"。**

同一条内容可能同时进入三张表，但每个表只记录它对应那个维度的信息。

```
洞察主表          意图原子表          选题总表
"我知道什么"      "我想做什么"        "我要写什么"
    │                │                  │
    │ 每条洞察       │ 每条意图          │ 每个选题
    │ 可推导出       │ 可筛选出          │ 源自
    │ 0~N条意图      │ 0~N个选题         │ 1~N条意图
    │                │                  │
    ▼                ▼                  ▼
 长期知识库        行动队列           写作队列
 可搜可筛可关联    有时间边界         有写作规划
```

- 已完成的事（"昨天做了Y"）→ 改状态为已完成

有时间边界——有开始、有结束（完成或放弃）。

### 文章类型枚举
- **A** — 反直觉洞察（"你以为X，其实Y"）
- **B** — 深度启发（"X的本质是Y"）
- **C** — 实用方法论（"做X的三步法"）
- **E** — 经验/案例（"我是怎么做到X的"）
- **G** — 故事型（"一个人/一件事改变了..."）

### 跟意图表的区别

| 意图原子表 | 选题总表 |
|-----------|---------|
| "想做什么" | "要写什么" |
| 可以是任何行动 | 只是写作 |
| 颗粒度细（原子级） | 颗粒度粗（一篇文章） |
| 标题方向+核心命题 | 3个标题方向 |
| 有论证骨架 | 有最强细节+潜在反驳 |
| 有爆发力/独特性评级 | 有写作难度+建议优先级 |

### 核心规则
- 每个选题应关联一个或多个意图原子（原始素材来源）
- 如果一个意图不适合写作（比如"做一个工具"），留在意图表，不进选题表
- 选题表里的才是真正的"写作队列"
- 爆发力≥4且独特性≥4的选题优先处理

### 什么该进来
- 有明确写作方向的意图
- 核心命题足够锐利
- 有可展开的论证素材

### 什么不该进来
- 还没想清楚的模糊想法（留在意图表）
- 不适合公开的内容（留在洞察表或wiki）

### 生命周期
待写 → 写作中 → 已发布 → 永久存档。

## 三表联动规则

### 流转方向

```
洞察主表（上游）──"这是什么"
  │
  │ 推导出意图/行动
  ▼
意图原子表（中游）──"我能拿它做什么"
  │
  │ 筛选出可写作的
  ▼
选题总表（下游）──"我要写什么"
```

### 关联标注规则
1. 意图表的"备注"字段标注"源自I-XXX"
2. 选题表的"原始素材来源"字段标注"源自I-XXX, I-YYY"
3. 洞察表的"案例"字段可引用选题编号（"详见S-09"）
4. **不反向重复建**：洞察已在表中时，意图只标注来源，不重写洞察

### 去重检查流程
```
1. 搜洞察主表：关键词匹配标题和核心简要
2. 搜意图原子表：关键词匹配意图描述
3. 搜选题总表：关键词匹配核心命题
4. 发现重复 → 不新建，更新已有记录
5. 未发现重复 → 新建
```
