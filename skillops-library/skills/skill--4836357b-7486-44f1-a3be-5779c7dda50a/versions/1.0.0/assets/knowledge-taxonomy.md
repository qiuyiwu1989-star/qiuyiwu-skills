## 归档规则

**已完成项目**：从 `项目知识库/` 移至 `洞察与外部知识/行业洞察/[项目名]归档/`
**已发布选题**：从 `内容创作库/选题库/待写/` 移至 `内容创作库/选题库/已发布/`
**成熟的想法**：从 `方法论与认知/散思录/` 整合到对应的方法论目录

归档操作由用户手动完成，Brain Agent 不主动建议归档（避免频繁打断）。
