# 深度长文锻造 · 从素材到非显然的论点

## 用途
把一堆原始素材（笔记 / 访谈 / 资料 / 一个模糊的感受）锻造成一篇能发布的深度文章。核心是先逼出一个**非显然的论点**，再用"现象 → 回归原点 → 关系重构 → 影响重塑"的骨架把它撑起来。专治"写出来像综述、没观点"。

## 何时调用（触发词）
"帮我写一篇深度文章" / "这堆素材能写成什么" / "我想讲清楚 X 这个现象" / "选题" / "这篇怎么写得有观点一点" / "深度长文"。

## 步骤
1. **找反直觉的缝**：通读素材，找一个"大家默认是 A、其实是 B"的点。这是文章的命根子。找不到 → 这篇还不值得写，回去再读 / 再访谈。
2. **一句话论点**：把那个缝写成一句**让人想反驳**的话。太安全（没人会反对）= 没观点；太离谱（站不住）= 标题党。
3. **四段骨架**：
   - **现象**：从一个具体、读者有共鸣的切口进入（别从定义进入）。
   - **回归原点**：这个现象的第一性原因是什么？剥掉表层解释。
   - **关系重构**：原来以为的因果 / 主次，其实该怎么重排？论点在这里发力。
   - **影响重塑**：如果论点成立，对读者的判断 / 行动意味着什么？
4. **二读时刻**：在文中埋 1–2 个"读者会停下来重读一遍"的句子（一个反转、一个精准类比）。
5. **删常识**：最后一遍专门删——凡是"读者本来就知道、AI 也会说"的句子，全删。

## 输出格式
先给【一句话论点】+【为什么它非显然】，再给四段式提纲（每段：小标题 + 2–3 句要点 + 那段的"二读句"候选），最后列【要删的常识清单】。不直接代写全文（除非用户明确要）——先把骨头搭对。

## 示例
输入："想写写为什么现在人不爱发朋友圈了。"
- ❌ 坏论点："因为隐私意识增强了。"（人人都这么说，没观点）
- ✅ 好论点："朋友圈的衰落不是因为人变内向，是因为'点赞'把表达异化成了表演——当每条都要被打分，沉默成了唯一不输的选项。"（反直觉、可反驳、有重构）

## 边界 / gotchas
- 最常见的失败是**伪论点**——换个说法的常识。检验：把论点丢给一个聪明朋友，他若说"这不显然吗"，重来。
- 别用 AI 腔过渡（"首先 / 其次 / 综上""在这个数字化时代"）。深度感来自具体，不来自连接词。
- "二读句"不能硬凑金句。它要么是精准类比，要么是把读者绕进去又拽出来的反转，凑出来的会很油。
- 素材不够别硬写。深度文章靠"素材密度"撑，稀素材写长 = 注水。
