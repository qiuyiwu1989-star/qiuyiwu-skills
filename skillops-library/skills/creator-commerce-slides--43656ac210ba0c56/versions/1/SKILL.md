# CC-011 创作者商业新粗野主义

整页文字、物件、关系与留白一起用图像工具生成。按页意设计，不用HTML拼图冒充整页生成。assets/含八张原创候选，选择相关页型作为风格参考；示例文案不是用户业务事实。


## 内容优先的表达构思

先理解内容，再设计讲法，最后应用视觉风格。本节优先于本Skill中的示例布局、默认页型及页数建议；用户明确指定的布局仍应遵守。模板固定视觉语言，不固定故事结构与构图。

生成前先形成一份简短表达简报：听众是谁；希望其理解、感受或采取什么行动；核心主张是什么；必须保留的事实、证据、限制与情绪转折是什么。已有信息足够就直接判断，不机械追问；只有影响讲法的关键缺失才询问。

根据内容选择叙事逻辑：故事按处境、变化、选择与结果推进；观点用依据、例子与成立条件支撑；机制明确参与者、作用和反馈；方法展示任务、操作与关键判断；选择按同维度比较与适用条件展开；文化表达可从生活细节、器物或场景进入。以上是候选讲法，不是另一组强制模板，允许混合或另创。

只有存在实质不同的讲法且用户尚未指定时，提出两种简短方向，解释各自突出什么；普通单页可自主选择，不把每次创作变成审批流程。单页确定表达任务，整套安排进入、推进、转折与停顿，再决定页数、构图、字图比例和视觉节奏。

封面、观点、对比等页型是参考词汇，不是必须凑齐的目录。允许纯文字页、证据页、连续场景或用户内容所需的新页型。不要为了套三步骤而改写过程、为了闭环添加因果、为了风格强放人物或器物；不能用通用口号替代原始细节。插画须解释动作、关系、证据或情绪，否则删掉或改为留白。

验收先看内容：能否说清本页为何采用这个讲法、图像增加了什么理解；原始事实、限定、情绪和关系是否保留；是否因套版发生删减、伪造或过度概括。再检查视觉一致性、文字可读性与尺寸。跨页保持字体、配色、笔触与必要角色一致，布局随内容变化。


## 视觉契约

- 暖白 #F7F5EF、近黑 #101010、粉 #F18ADF、淡紫 #B8B4F4、明黄 #FFD82B。正文页以暖白缓冲，章节或结尾可用单色大底，不把每页涂满三种强调色。
- 极粗紧凑的现代中文黑体标题，清晰无衬线正文；大字建立张力，细黑线分组。避免毛笔手写字、复古网点、纸张做旧和厚漫画面板。
- 简洁黑轮廓物件、克制平面投影与色块。一个视觉重点，不堆拟物细节。圆盘、作品卡、信封、阶梯是可选语汇，必须服务语义。
- 默认无人物与身体局部，避免用第三方品牌字母、原有吉祥物或收益数字装饰。图表数据必须来自用户或可核实材料。
- 目标四边9%关键内容安全区，约35%留白；背景色块可以出血，正文不能。原样页边缘偏紧时不可原封照搬。

## 文字与结构

先提炼核心主张，再分清事实、解释、证据与条件。文字增加时先去大配图，使用分组和字阶；保留数字、限制、否定与责任主体。仍放不下就拆页，不缩成小字、不静默删核心条件。

八种页型：
- COVER：短主张、一句解释、单个价值物件；可选简短底部索引。
- SECTION：编号与转折句，一个小物件，留白主导。
- CLAIM：观点与解释两级，单个语义关系图。
- COMPARE：统一维度对齐双方，保持文字权重相称，不伪造结论。
- STEPS：编号、动作、必要说明；默认示例三步，实际数量由内容决定。
- CYCLE：只表达真实循环，逐一检查箭头；不能把顺序关系硬闭环。
- SYSTEM：用分组与联系表达能力、结构或经营关系，不强制三列；有回流才画回流。
- END：行动句、致谢、后贴二维码留白；不生成假二维码。

## 生成与验收

提示词包含准确上屏文字、布局、页型、色彩、图文比例与安全区。使用当前图像工具；若不可用，如实说明。

默认横版1920×1080。实测原生和交付尺寸，保留原图与提示词；极小整数比例差可规范化，明显比例差重新生成或等比适配，不能强拉伸。不要添加颜色不匹配的补边。

检查文字、关系、边距与远看可读性，不宣称用户已认可所有候选。生成八页不自动授权生产发布。文件集中保存到既有创作工作区。
