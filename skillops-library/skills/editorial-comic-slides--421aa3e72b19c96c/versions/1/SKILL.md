# EC-003 编辑漫画 v1.0.0


## 内容优先的表达构思

先理解内容，再设计讲法，最后应用视觉风格。本节优先于本Skill中的示例布局、默认页型及页数建议；用户明确指定的布局仍应遵守。模板固定视觉语言，不固定故事结构与构图。

生成前先形成一份简短表达简报：听众是谁；希望其理解、感受或采取什么行动；核心主张是什么；必须保留的事实、证据、限制与情绪转折是什么。已有信息足够就直接判断，不机械追问；只有影响讲法的关键缺失才询问。

根据内容选择叙事逻辑：故事按处境、变化、选择与结果推进；观点用依据、例子与成立条件支撑；机制明确参与者、作用和反馈；方法展示任务、操作与关键判断；选择按同维度比较与适用条件展开；文化表达可从生活细节、器物或场景进入。以上是候选讲法，不是另一组强制模板，允许混合或另创。

只有存在实质不同的讲法且用户尚未指定时，提出两种简短方向，解释各自突出什么；普通单页可自主选择，不把每次创作变成审批流程。单页确定表达任务，整套安排进入、推进、转折与停顿，再决定页数、构图、字图比例和视觉节奏。

封面、观点、对比等页型是参考词汇，不是必须凑齐的目录。允许纯文字页、证据页、连续场景或用户内容所需的新页型。不要为了套三步骤而改写过程、为了闭环添加因果、为了风格强放人物或器物；不能用通用口号替代原始细节。插画须解释动作、关系、证据或情绪，否则删掉或改为留白。

验收先看内容：能否说清本页为何采用这个讲法、图像增加了什么理解；原始事实、限定、情绪和关系是否保留；是否因套版发生删减、伪造或过度概括。再检查视觉一致性、文字可读性与尺寸。跨页保持字体、配色、笔触与必要角色一致，布局随内容变化。

Bun-haired woman in blue shirt and gray-haired glasses mentor; stable adult character identity. Use sparse meaningful panels ONLY when page semantics benefit, vary camera distance, no background rooms, crowd, plant or extra speech bubbles.

以上为视觉特征，不声称生成图使用某个精确字体文件。标题、标签、说明的笔触重量与材质协调，不能只换配色保留别套字体。

## 执行

先确定受众、唯一主张、必要事实与关系，再选页型。每页通过可用image工具独立生成整页文字和插画；不能用一张主视觉反复加HTML文字冒充多页成品。参考仅锁定风格，不把每个主题都画成服装。讲解方法与媒介分开选择。

一场景通常1–2人，约1–3件必要道具；不加路人、办公室、盆栽、杯子和微字。层次靠主次、前后遮挡、尺度与明暗；简约先删背景和细节，不删动作与必要关系。系统页可因信息需要调整密度。

## 八页型

COVER一个主题与主场景；SECTION章节名和悬念问题；CLAIM一个主张与可观察动作；COMPARE固定同任务维度表达差异；STEPS区分并列原则与先后过程；CYCLE逐边核对主循环与分支；SYSTEM保留真实分组状态，不把关系线画成自动执行；END呼应封面角色与排字，留联系区空白不画假二维码。

## 验收与保存

逐字核对标题说明、数据与来源；禁止新增利润、客户、承诺、伪公式或伪尺度。技术示意注明状态，图形分类不替代完整产品清单。无Logo伪造、二维码或水印。

默认横版JPG1920×1080，生成后实测尺寸；左右至少115px、上下81px安全区。用等比缩放补边规范，不拉伸；记录原生和最终尺寸，不将上采样说成原生高分辨率。检查字体、动作、关系、手势与同套一致性，必要时有针对性修订。保存原图、最终图、完整提示词、来源和修订记录，不覆盖旧版本。
