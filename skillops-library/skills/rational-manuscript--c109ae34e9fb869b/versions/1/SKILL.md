# RM-002 理性手稿·简约版 v1.0.0

从 [简约参考](assets/style-reference.jpg) 锁定风格；封面与结尾对照 [封面](assets/cover-reference.jpg)、[结尾](assets/end-reference.jpg)。这是用户明确要求沉淀的第二套模板方向；新增七张示范尚不代表逐张认可。


## 内容优先的表达构思

先理解内容，再设计讲法，最后应用视觉风格。本节优先于本Skill中的示例布局、默认页型及页数建议；用户明确指定的布局仍应遵守。模板固定视觉语言，不固定故事结构与构图。

生成前先形成一份简短表达简报：听众是谁；希望其理解、感受或采取什么行动；核心主张是什么；必须保留的事实、证据、限制与情绪转折是什么。已有信息足够就直接判断，不机械追问；只有影响讲法的关键缺失才询问。

根据内容选择叙事逻辑：故事按处境、变化、选择与结果推进；观点用依据、例子与成立条件支撑；机制明确参与者、作用和反馈；方法展示任务、操作与关键判断；选择按同维度比较与适用条件展开；文化表达可从生活细节、器物或场景进入。以上是候选讲法，不是另一组强制模板，允许混合或另创。

只有存在实质不同的讲法且用户尚未指定时，提出两种简短方向，解释各自突出什么；普通单页可自主选择，不把每次创作变成审批流程。单页确定表达任务，整套安排进入、推进、转折与停顿，再决定页数、构图、字图比例和视觉节奏。

封面、观点、对比等页型是参考词汇，不是必须凑齐的目录。允许纯文字页、证据页、连续场景或用户内容所需的新页型。不要为了套三步骤而改写过程、为了闭环添加因果、为了风格强放人物或器物；不能用通用口号替代原始细节。插画须解释动作、关系、证据或情绪，否则删掉或改为留白。

验收先看内容：能否说清本页为何采用这个讲法、图像增加了什么理解；原始事实、限定、情绪和关系是否保留；是否因套版发生删减、伪造或过度概括。再检查视觉一致性、文字可读性与尺寸。跨页保持字体、配色、笔触与必要角色一致，布局随内容变化。


## 核心方法

先理解本页唯一主张，选可观察动作或清楚关系。用image整页生成标题、说明、人物、关系和留白；不能用HTML文字加一张主视觉或同图套八种排版冒充整页创作。HTML只作为浏览/调用界面。

每页重新构思，参考定义媒介、角色和排字，不强迫所有主题使用服装、设计图或导师。讲解方法（直接、故事、案例、提问）与风格独立。

## 视觉与字体

暖纸白#F6F4ED、石墨#414640、浅赭#AA8650。工整克制的工程手写字：主标题深重，短标题中重，说明较轻且可读。不要粗马克笔字、毛笔飞白或随机换成细宋体。图片生成字形按视觉约束，不声称精确字体文件。

线重三层：关键手部与物件轮廓清楚，人物与衣着中等，辅助结构线更淡。空间靠纸张遮挡、尺度与前后位置、小范围接触阴影；不要整幅均匀发灰，也不要加密排线制造层次。

人物为完整成熟成年人，有准确动作、简洁衣着和克制五官；不退化为火柴人，也不变成写实肖像。当前OPC示例主角是深色发髻女设计者、浅灰外衫与深色内搭；导师灰发眼镜。新项目可另定人物，同套封面与结尾保持一致。

## 简约约束

一场景一个动作，通常1–2人、约1–3件必要物件。约40%–50%留白。先删背景网格、放大圈、布料堆、图纸堆、盆栽杯子、密集衣褶和细发丝，保留动作与关系。系统页因结构需要调整，不机械删除必要节点。

“要层次”优先改主次、线重、尺度和遮挡；“再简约”删线与道具，不删核心关系、不消除已建立的层级。

## 页型

- COVER：一个主要场景与清楚标题，角色在END呼应。
- SECTION：编号、章节名、一个引导问题，保留悬念。
- CLAIM：一个主张与一个结果可验证的动作。
- COMPARE：固定比较维度；同任务行为/结果产生差异，箭头只表达真实变化。
- STEPS：可以表达并列方法或原则，也可表达有证据的顺序过程；必须区分，不能自动加阶段箭头。
- CYCLE：逐条列出节点/边与方向；主循环、中心关系与分支分开。
- SYSTEM：保留真实分组、状态与权限；无箭头关系线不代表自动执行。
- END：呼应封面角色、字体与媒介，联系区留空，不生成二维码。

## 准确性与交付

用户原文/数字优先，禁止新增客户、收益承诺、伪公式或维度。示意分组不得冒充完整产品清单。图内文字逐字检查，人物手势与关系方向逐项核对。无假Logo、假二维码或伪数据。

默认横版JPG、最终实测1920×1080。左右至少115px、上下81px安全区。生成后读取真实宽高；轻微比例差用等比缩放与同色补边，不拉伸，不声称上采样提升原生细节。记录原始尺寸、最终尺寸与处理方式。
