# Design Review · 设计评审自动化

## 这是什么

设计评审是构成的"质检员"——在任何设计产出交付前，自动检查是否符合质量标准，输出结构化评审报告。

**核心价值：** 不把问题推给用户。交付前自己先审一遍。

## 工作流程

```
Step 1：接收设计产出（HTML文件/飞书文档/图片/视频）
  ↓
Step 2：自动检查（6大维度，逐项打分）
  ├─ 排版反slop检查
  ├─ 色彩校准检查
  ├─ 布局检查
  ├─ 交互状态检查
  ├─ 动画物理化检查
  └─ 品牌一致性检查（如有design-tokens）
  ↓
Step 3：输出评审报告
  ├─ 总分（满分100）
  ├─ 各维度得分+具体问题
  └─ 改进建议（可执行）
  ↓
Step 4：判断
  ├─ ≥80分 → 通过，可交付
  ├─ 60-79分 → 需修正，列出必须改的项
  └─ <60分 → 重做，列出致命问题
```

## 6大检查维度

### 1. 排版反slop（20分）

| # | 检查项 | 扣分规则 |
|---|--------|---------|
| 1.1 | 高端场景用了Inter字体 | -5分（应用Geist/Outfit/Cabinet Grotesk/Satoshi） |
| 1.2 | Dashboard/软件UI用了衬线体 | -5分（只用Sans-Serif+Mono配对） |
| 1.3 | 正文行高<1.4或>2.0 | -3分 |
| 1.4 | 中英文混排无间距 | -3分 |
| 1.5 | 标题层级混乱（跳级） | -4分 |

### 2. 色彩校准（20分）

| # | 检查项 | 扣分规则 |
|---|--------|---------|
| 2.1 | 强调色超过1个 | -5分 |
| 2.2 | 强调色饱和度>80% | -5分 |
| 2.3 | 使用了蓝紫色系 | -5分（禁用，与略懂AI设计指南冲突） |
| 2.4 | 混用了暖灰和冷灰 | -3分 |
| 2.5 | 文字与背景对比度<4.5:1 | -2分（可访问性） |

### 3. 布局去中心化（20分）

| # | 检查项 | 扣分规则 |
|---|--------|---------|
| 3.1 | 居中Hero（LAYOUT_VARIANCE>4） | -5分（除非特殊场景） |
| 3.2 | 全页面居中对齐 | -5分（应有分屏/左对齐/非对称） |
| 3.3 | 用flex百分比计算而非Grid | -3分 |
| 3.4 | 留白不均匀 | -4分 |
| 3.5 | 信息密度不均（某些区域太空/太挤） | -3分 |

### 4. 反卡片泛滥（15分）

| # | 检查项 | 扣分规则 |
|---|--------|---------|
| 4.1 | 数据密集场景用了通用card容器 | -5分（应用border-t/divide-y/负空间） |
| 4.2 | 阴影未着背景色 | -3分 |
| 4.3 | 卡片套卡片 | -4分 |
| 4.4 | 列表项全用card包裹 | -3分 |

### 5. 交互状态全覆盖（15分）

| # | 检查项 | 扣分规则 |
|---|--------|---------|
| 5.1 | 缺Loading状态（骨架屏） | -5分 |
| 5.2 | 缺Empty状态（引导态） | -5分 |
| 5.3 | 缺Error状态（内联错误） | -5分 |
| 5.4 | 缺:active按压反馈 | -3分（应有-translate-y-[1px]或scale-[0.98]） |

### 6. 动画物理化（10分）

| # | 检查项 | 扣分规则 |
|---|--------|---------|
| 6.1 | 使用线性easing | -3分（应用弹簧物理stiffness:100, damping:20） |
| 6.2 | 连续动画用useState而非useMotionValue | -3分 |
| 6.3 | 交错动画未用staggerChildren | -2分 |
| 6.4 | 动画时长不一致 | -2分 |

## 附加检查（如有design-tokens）

| # | 检查项 | 扣分规则 |
|---|--------|---------|
| A.1 | 颜色不符合品牌token | -5分 |
| A.2 | 字体不符合品牌token | -5分 |
| A.3 | 间距不符合品牌token | -3分 |

## 评审报告格式

```
📋 设计评审报告
━━━━━━━━━━━━━━━━━━━━
📄 文件：{filename}
🎯 总分：{score}/100
✅/⚠️/❌ 状态：通过/需修正/重做

📊 维度得分：
  1. 排版反slop    {score}/20
  2. 色彩校准      {score}/20
  3. 布局去中心化  {score}/20
  4. 反卡片泛滥    {score}/15
  5. 交互状态      {score}/15
  6. 动画物理化    {score}/10
  附加. 品牌一致性 {score}/15（如有tokens）

🔴 必须修正（≥80分才可交付）：
  - [问题1]：{具体位置} → {改进建议}
  - [问题2]：{具体位置} → {改进建议}

🟡 建议优化（非必须但会更好）：
  - [建议1]：{具体位置} → {改进建议}

💡 总评：{一句话整体评价}
```

## 适用范围

- HTML演示/网页（frontend-slides/html-ppt-skill/guizang-ppt-skill/huqiu-design的产出）
- 飞书文档（feishu-doc-visual的产出，检查排版规范）
- 不适用于：纯图片/视频（有独立的质量标准）

## 安全边界

| 规则 | 说明 |
|------|------|
| **只读不改** | 评审只检查，不自动修改文件 |
| **结果写自己目录** | 评审报告写入构成自己的产出目录 |
| **不删除** | 评审结果不自动触发删除 |
