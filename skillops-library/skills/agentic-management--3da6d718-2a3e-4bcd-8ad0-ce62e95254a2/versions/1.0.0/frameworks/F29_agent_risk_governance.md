## SKILL 定位
**核心判断**：提示注入是当前最活跃的攻击面，任何处理外部输入的Agent今天就面临这个威胁，不是未来的假想风险。风险治理必须持续维护，建立了机制但不更新，等于没有治理。

## 七类新型风险速查

| 风险类型 | 活跃度 | 最紧迫防御行动 |
|---------|--------|-------------|
| ① 幻觉风险 | 中 | 双重验证 + Groundedness评分 |
| **② 提示注入 ★** | **最活跃** | **输入隔离 + 指令来源验证（今天就做）** |
| ③ 工具滥用 | 高 | 最小权限原则 + 工具调用审计 |
| ④ 多Agent级联失败 | 高（静默） | 跨Agent语义验证 + 级联熔断 |
| ⑤ 代理权风险 | 中高 | 权限时效控制 + 操作范围监控 |
| ⑥ 数据泄露 | 中 | 知识库访问控制 + RAG输出过滤 |
| ⑦ 供应商绑定 | 战略风险 | 多供应商策略 + MCP/A2A标准化 |

## HITL/HOTL/HAL 速查
- **HITL**（循环内）= 高风险 / L0-L2 / 每步人工审批
- **HOTL**（循环上）= 中等风险 / L3 / 自动运行+异常介入
- **HAL**（循环上方）= 低风险 / L4-L5 / 设定边界+定期复审
- **规则**：风险等级不允许跨级跳跃，高风险必须从HITL验证

## 合规三大支柱
NIST AI RMF（美国基础）/ EU AI Act（欧盟强制，2025.8已生效）/ ISO 42001（可认证标准）

## 四步执行
**S1** 建立风险注册表（七类风险全部评估 + 发生概率×影响程度评分，上线前必备）
**S2** 为每个Agent配置HITL/HOTL/HAL机制（基于风险评分，不允许跨级）
**S3** 建立提示注入专项防御（处理外部输入的Agent最高优先级）
**S4** 季度更新风险注册表（新功能/外部安全研究/内部事件三个触发来源）

## 典型误区
- 只关注传统安全（防火墙/代码审计）→ 对七类新型风险几乎无效
- 提示注入当低优先级 → 已有大量真实CVE，攻击门槛极低
- 风险注册表一次性不维护 → 安全是持续工作，不是一次审查
