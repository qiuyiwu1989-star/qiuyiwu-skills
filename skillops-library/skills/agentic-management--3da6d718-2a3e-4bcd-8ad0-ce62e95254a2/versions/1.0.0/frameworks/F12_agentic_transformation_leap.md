## SKILL 定位

**做什么**：诊断企业当前所处的转型阶段，识别跃迁卡点，制定针对性的跃迁推进计划。

**核心判断**：AI转型失败的核心原因不是技术，而是文化和结构。跃迁不是时间到了自然发生，而是需要满足「锁定条件」被解锁才能真正跨越。

---

## 五阶段速查

| 阶段 | 核心信号 | 典型卡点 |
|------|---------|---------|
| S1 感知期 | 个人自发用AI，管理层未关注 | 无正式预算，无被允许失败的文化 |
| S2 试验期 | 1-3个Agent场景初见成效 | 成功案例无法复制，各自为战 |
| S3 局部落地期 | Agent>10个，各业务线落地 | 编排层缺位，中台未建，治理跟不上 |
| S4 系统整合期 | 中台架构建立，编排层成型 | AI仍是「工具」，制度未更新 |
| S5 原生智能体期 | AI是默认工作方式 | 已到达，维持并持续进化 |

## 五维诊断评分

**评分方式**：对照每个维度，选择最接近当前状态的分值

### 技术基础 (0-10分)
- 0-2分：无AI工具使用，或仅个别员工使用
- 3-4分：多人使用AI工具，但无系统化部署
- 5-7分：有Agent部署，但缺乏统一管理和治理
- 8-9分：Agent中台架构完整，有版本管理和安全控制
- 10分：技术生态持续进化，数据飞轮有效运转

### 组织结构 (0-10分)
- 0-2分：传统部门制，无人机协作机制
- 3-4分：局部人机协作，但无统一架构
- 5-7分：有双前台雏形，无Agent中台
- 8-9分：三层架构（中台/双前台/后台）稳定运行
- 10分：Agentic Network全面落地，五类节点清晰

### 人才能力 (0-10分)
- 0-2分：无AI相关专职岗位
- 3-4分：有AI技术岗位，但无编排层
- 5-7分：有Agent用户和技术支持，但编排层空缺
- 8-9分：编排层岗位成型（Agent Owner/AI Workforce Manager）
- 10分：四层岗位体系完整，有完善的岗位演化培养机制

### 工作文化 (0-10分)
- 0-2分：组织整体抵触或忽视AI
- 3-4分：鼓励个人尝试，但无组织层面推动
- 5-7分：部分场景默认考虑AI方案，管理层有明确态度
- 8-9分：多数流程将AI作为优先选项，有失败容忍文化
- 10分：AI-First是默认工作方式，新员工入职即要求AI协同能力

### 治理风控 (0-10分)
- 0-2分：无任何治理机制
- 3-4分：有基础合规意识，偶尔记录AI使用
- 5-7分：有RACI-A文档，有部分Agent的边界定义，但未系统实现
- 8-9分：三系统（边界/升级/恢复）运行，DAL等级已标注
- 10分：自适应治理，季度演练，案例持续回流优化

## 第二步：执行分析引擎

### S1 · 五维诊断

```
五维评分结果

技术基础：X分 | 组织结构：X分 | 人才能力：X分
工作文化：X分 | 治理风控：X分

总分：X/50分 → 对应阶段：[感知/试验/局部落地/系统整合/原生]

最低分维度：[维度名] = X分
→ 这是当前跃迁的核心瓶颈（解锁动作应优先指向此维度）

维度差异分析：
  最高分 - 最低分 = X分
  如差距 > 3分：存在严重的维度失衡，优先解决最低分维度
  如差距 ≤ 3分：相对均衡，可按总分阶段推进
```

### S2 · 锁定条件分析

```
当前跃迁边界：[S?→S?]

标准锁定条件：[参考跃迁条件表]

深度分析：锁定的根本原因是什么？
  □ 技术原因（工具/系统未就绪）
  □ 结构原因（编排层缺位/中台未建/治理机制缺失）
  □ 文化原因（管理层未真正认可/员工系统性抵触）
  □ 制度原因（考核/晋升未包含AI协同/无AI培训资源）

```

```

6-12个月
  Step 7 制度化固化：[将AI协同写入哪些KPI/晋升标准/流程规范]
  Step 8 形成文化：[AI从可选工具变成默认方式的制度保障]

跃迁验证条件（宣告进入下一阶段前必须验证）：
  [具体的、可验证的跃迁标准，不是PPT展示]
```

### S4 · 季度追踪

```
季度复评机制

每季度重新五维评分，追踪变化

虚假跃迁警示（常见模式）：
  □ 有了架构图但没有实际运行的系统（治理分虚高）
  □ 有了AI培训但工作方式没改变（文化分虚高）
  □ 设立了Agent岗位但职责不清（人才分虚高）

进入下一阶段的验证方式：
  感知→试验：管理层公开背书 + 专属预算已分配
  试验→局部落地：至少1个Agent场景有可复制的标准化模板
  局部→系统整合：Agent中台真实处理请求量 > X/天 + 有专职Agent Owner
  系统整合→原生：新员工入职默认要求AI协同能力 + AI写入绩效考核
```
