## SKILL 定位
**核心判断**：初期（0-6个月）负ROI是正常的投资积累期，不是放弃信号。「3个月看不到ROI就放弃」往往发生在恰好跨越Break-even Point之前——这是最常见的短视决策。

## 核心公式
```
Agent ROI = （量化价值收益 - 总拥有成本TCO）÷ 总拥有成本 × 100%
```

## 四类价值来源

| 价值来源 | 计算方式 | 量化难度 | 最常见错误 |
|---------|---------|---------|----------|
| 人力成本节省 | 替代人工小时×时薪（含社保） | 易 | 混淆技术替代率和真实替代率 |
| 效率提升收益 | 产出增量×单位产出价值 | 中 | 归因时未排除其他影响因素 |
| 收入增长贡献 | 归因交易金额×归因比例 | 难 | 缺少A/B实验，归因不可信 |
| 风险降低价值 | 历史事件损失×风险降低比例 | 难 | 需要历史基线，新系统初期无法量化 |

## ROI时间曲线三阶段

```
初期 0-6个月:   ROI < 0  ← 正常，建设成本高收益未释放
成长期 6-18月:  ROI转正  ← CPTA下降，飞轮开始转动
成熟期 18月+:   ROI峰值  ← 摊销完成，这才是真正回报期
```

## TCO完整构成（最容易遗漏哪项）
初始建设（CapEx）+ 持续运营（OpEx）+ **治理合规成本（高风险行业可达20-30%，最容易遗漏）** + 机会成本

## 四步执行
**S1** 建立四类价值量化模型（渐进归因：从人力节省开始，逐步引入复杂归因）
**S2** 计算完整TCO（特别核查治理合规成本是否遗漏）
**S3** 绘制ROI时间曲线（向管理层展示时**必须包含时间曲线**）
**S4** 建立季度ROI复盘（初始预测往往不准，持续校正才是真正价值）

## 渐进归因的组织价值
一个不完美但被财务团队接受的ROI模型，比一个完美但无法获得共识的模型更有价值——推进Agent ROI的最大障碍是跨部门协作，不是技术问题
