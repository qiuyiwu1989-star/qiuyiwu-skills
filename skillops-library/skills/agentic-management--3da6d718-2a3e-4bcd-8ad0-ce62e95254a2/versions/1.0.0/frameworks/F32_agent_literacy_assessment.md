## SKILL 定位
**核心判断**：AI能力的核心不是「会用多少工具」，而是「能组织多少能力」。能力结构（四维分布）比能力等级（单一分数）更重要——四维均衡的人和单维极强的人在不同岗位有完全不同的价值。

## 四维×五级矩阵速查

| 维度 | 核心判断问题 | L3的典型表现 |
|------|------------|------------|
| 理解力 | 知道AI在哪里会失败吗？ | 能识别幻觉/分布外泛化，并在工作中调整策略 |
| 使用力 | 能用AI把一件事做好吗？ | 多轮交互迭代，能组合工具解决具体问题 |
| **编排力** | **能让AI替自己完成流程吗？** | **设计端到端Agent工作流，自己审核而非执行** |
| 设计力 | 能为组织构建AI能力基础设施吗？ | 从零构建含Eval体系的Agent系统供他人使用 |

## 五个成熟度等级
L1意识级 → L2操作级 → L3协同级 → L4编排级 → L5架构级

## 岗位导向的评估重点
- 编排层岗位（Agent Owner）→ 重点：编排力L4 + 理解力L3
- 能力层岗位（Context Engineer）→ 重点：理解力L4 + 设计力L3
- 直接产出类岗位 → 重点：使用力L3 + 理解力L3

## 四步执行
**S1** 选择与岗位匹配的评估方式（工具测试/设计题/案例分析/项目交付）
**S2** 四维独立评分 + 绘制雷达图（能力结构可视化）
**S3** 识别能力结构差距（最关键的差距维度，不是所有差距都同等重要）
**S4** 制定差异化发展路径（集中投入最关键差距维度，差异化培训比统一课程效率高3-5倍）

## 典型误区
- 只评估工具熟悉度→ 工具使用力是四维中最容易商品化的
- 用单维深度替代四维评估→ 提示词专家≠L3能力
- 评估结果不与培训决策绑定→ 评了但没用
