## SKILL 定位
**做什么**：在自主性×人格化双轴上定位产品，确认演进路径，对齐交互/定价/合规下游策略，建立季度定位复审机制。
**核心判断**：定位错误导致交互/定价/合规系统性偏差，这些偏差往往要到市场验证失败后才被发现。

## 双轴四象限速查

| 象限 | 自主性 | 人格化 | 定价 | 合规级别 |
|------|--------|--------|------|---------|
| 工具型 | L0-L2 | 低 | 使用量/席位 | 极低 |
| 助理型 | L0-L2 | 高 | 订阅制 | 情感/内容安全 |
| 同事型 | L3-L4 | 低 | 结果定价 | 操作审计+边界治理 |
| 数字员工型 | L4-L5 | 高 | SLA+结果分成 | 最高，CATER五维全覆盖 |

## 执行步骤

**S1 当前定位**：评估实际使用模式（用户主动操控 vs 委托执行），在双轴上标注位置

**S2 目标定位**：12-24个月目标位置 + 演进路径里程碑（自主性提升的工程条件 + 信任建设条件）

**S3 下游对齐**：检查交互/定价/合规是否与定位一致，记录错位项制定对齐计划

**S4 复审机制**：季度重新评估DAL等级是否漂移，触发条件：DAL实际等级比声明高1级以上

## 典型误区
- 当精确测量工具而非战略讨论工具 → APS是定性框架
- 把自主性提升当唯一方向 → 各象限有独立商业价值
- 定位与定价/SLA/合规脱节 → 定位必须驱动实际决策
