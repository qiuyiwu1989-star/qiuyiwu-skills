## SKILL 定位
**做什么**：建立三指标追踪体系，诊断PMF阶段，制定针对性改进计划，判断扩张时机。
**核心判断**：Agent PMF不是「用户喜不喜欢」，而是「用户敢不敢继续托付」。高DAU+低Re-delegation = 假PMF。

## 三指标速查

| 指标 | 含义 | 健康阈值 | 单独失败说明 |
|------|------|---------|------------|
| 任务完成率 | 端到端完成，非步骤完成 | 结构化任务≥85% | 基础能力不够 |
| Override率 | 用户主动覆盖（排除正常协作）| <10% | 能力够但信任未建立 |
| **再次委托率** | **最重要**：第一次后愿意再次委托 | **>60%强PMF>80%** | **单次满意≠持续依赖** |

## PMF阶段诊断
- **PMF前期**：完成率<70% 或 Override>40% → 优先提升基础能力
- **假PMF**：完成率高+Override低，但Re-delegation<40% → 深访为什么不再次委托
- **弱PMF**：三指标基本达标但未到强阈值 → 打磨核心场景，暂缓扩张
- **强PMF**：三指标全部达标 → 可加速扩张

## 执行步骤
**S1** 建立三指标追踪体系（精确定义每个指标的计算方式）
**S2** 评估当前PMF状态，识别最薄弱维度
**S3** 90天针对性改进计划（单一维度突破，不均匀用力）
**S4** PMF验证：三指标稳定性确认 + 跨用户群体验证 → 扩张决策

## 典型误区
- 用传统DAU/MAU衡量Agent PMF → 活跃≠托付信任
- 技术完成率当PMF指标 → 需基于JTBO的结果定义计算
- 只追踪一个指标 → 三指标各有盲点，必须组合使用
