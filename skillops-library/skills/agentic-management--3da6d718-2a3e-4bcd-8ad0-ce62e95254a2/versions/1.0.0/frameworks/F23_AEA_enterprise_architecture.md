## SKILL 定位
**核心判断**：协议层（MCP+A2A）是未来十年最重要的战略投资，优先级高于模型选型。安全与观测性必须横贯所有层级，不只在顶层治理层。

## 六层架构速查

| 层级 | 名称 | 战略意义 | 成熟度关注点 |
|------|------|---------|------------|
| L1 | 基础模型层 | 管理多模型能力池 | 多模型路由+供应商风险管控 |
| **L2 ★** | **协议层（MCP+A2A）** | **未来十年最重要的基础设施投资** | **MCP接入数/A2A就绪度** |
| L3 | Agent运行时 | 从实验到生产的关键能力 | AgentOps+状态持久化+Kill Switch |
| L4 | Skill&工具注册 | 对应框架21 Skill治理 | Skill Hub质量+RBAC+遥测 |
| L5 | 编排层 | 单点→系统能力的跃迁 | 对应MAS架构选型（框架19） |
| L6 | 治理&身份（横贯所有层）| 安全不是顶层盖子，是每层内壁 | 各层是否内嵌安全约束 |

## MCP vs A2A
- **MCP**：LLM→工具/数据的垂直集成（给Agent装工具）
- **A2A**：Agent→Agent的水平协作（让Agent之间交付任务）
- 两者将成为「AI版HTTP+TCP」，早期采纳获得持久先发优势

## 四步执行
**S1** 评估六层成熟度（1-5分，绘制雷达图），识别最薄弱层
**S2** 优先建设协议层（L2）：MCP接入路线图 + A2A就绪度评估
**S3** 确保治理层横贯各层（逐层检查安全内置情况）
**S4** 建立跨层版本协同机制（对接框架22五线版本追踪）

## 最重要的设计原则
安全不是顶层的盖子，而是每一层的内壁。L6负责综合管控，不负责全部安全——如果L6承担了所有安全责任，说明L1-L5每一层都有安全盲点。
