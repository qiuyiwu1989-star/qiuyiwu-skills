## SKILL 定位
**核心判断**：升级到新版模型后原有Prompt性能下降，是最常见的Agent工程陷阱。五条版本线的协同管理，是Agent工程与传统软件工程最根本的差异之一。

## 五大工程原则速查

| 原则 | 核心要求 | 典型错误 |
|------|---------|---------|
| 高度原则 | 分层提示：角色定义/行为边界/输出规范 | 所有约束混在一个提示里 |
| Token精算 | 每个Token都有决策贡献，可降成本30-50% | 「放越多越好」 |
| 压缩策略 | 结构化摘要保留关键决策节点 | 简单截断历史对话 |
| 即时探索 | 按需检索，需要时才注入 | 任务开始一次性加载所有信息 |
| 跨会话衔接 | 状态文件记录进度，新会话无缝接续 | 任务中断后从零开始 |

## 五条版本线
模型版本 / Prompt版本 / Skill版本 / Tool/MCP版本 / Context/Memory版本
**原则**：任意一条升级都需要运行完整Golden Task Set验证，单次只升级一条

## 四层记忆架构
- 工作记忆：当前会话，上下文窗口
- 情景记忆：历史会话关键事件，需压缩存储（最常被忽视）
- 语义记忆：领域知识，RAG系统提供
- 程序记忆：操作步骤，最适合封装为Skill（框架21）

## 四步执行
**S1** 审计上下文Token分布，识别冗余信息（通常20-40%可安全压缩）
**S2** 设计分层提示结构（三层：角色/行为/任务）
**S3** 实施五线版本追踪（配置管理 + 升级协议）
**S4** 构建四层记忆管理方案（特别关注情景记忆压缩策略）
