# 工具二 · 开篇模式库

> 本质：把读者放进问题里。读者读完开篇，应该已经在问一个问题，而不是收到了一个答案。

核心原则：**前150字必须建立问题，不给答案。** 读者没有感受到问题之前，给他观点是没有意义的。

---

## 五种开篇模式

---

### O-01｜场景沉浸

**机制**：带读者进入一个亲历的具体现场，让他和你一起「看」，然后产生困惑。

**特征**：第一人称 + 有时间地点 + 有具体细节 + 不急于给结论

**结构**：进入现场 → 看到了什么 → 为什么这让我困惑/震动

**示例**：
> 「前段时间，我去参观了一家幼儿园。说实话，去之前我并没有抱太大期待——在我的印象里，幼儿园是AI渗透最慢的地方……结果走进去，被震住了。」

**适用**：有亲身经历的选题；需要建立信任感的议题；感性话题

**使用时注意**：现场细节要真实具体，不要写成「某天我去了某个地方」。时间、地点、感受要到位。

---

### O-02｜数据震撼

**机制**：用一个反常识的数字制造不适感，数字本身就是谜，读者想知道为什么。

**特征**：数字出现在第一句 + 数字要反常识 + 不立刻解释

**结构**：这个数字 → 它让我不安/困惑 → 引出真正的问题

**示例**：
> 「某AI角色扮演平台，月活用户已经超过两亿。很多用户坦言，他们每天和AI聊的时长，已经超过了和任何一个真实的人。这件事本身不让我不安。让我不安的，是做AI产品的人看到这个数据时的第一反应……」

**适用**：有可靠数据支撑的议题；需要建立紧迫感的话题

**使用时注意**：数字必须真实可验证，不能虚构；数字要反常识，平庸的数字没有冲击力。

---

### O-03｜反常识宣判

**机制**：第一句话就说出颠覆认知的结论，然后解释「我为什么这么说」。读者要先被震住，才有兴趣听你解释。

**特征**：结论在前 + 不解释 + 制造认知摩擦

**结构**：反常识结论 → 读者预期的说法是什么 → 为什么我的判断不一样

**示例**：
> 「有一件事，我花了半年才想明白——被教育的时间越长，创造力反而越弱。」

**适用**：有强烈反常识判断的选题；宣判型题目配套使用

**使用时注意**：结论要够强，不能只是「有一点不一样」；第一句话后面不能立刻解释，要让读者坐不住。

---

### O-04｜困惑自白

**机制**：用「我一直想不明白一件事」带读者进入思考过程，示弱，真诚，邀请共同探索。

**特征**：第一人称 + 真实的困惑 + 不装作已经有答案

**结构**：我的困惑 → 为什么这个困惑让我停下来 → 我开始重新想这件事

**示例**：
> 「我经常问自己一个问题：我们到底身处一个什么样的时代转折点？不是那种泛泛的「AI改变世界」，而是要真正看清楚——这次技术浪潮的本质是什么？」

**适用**：宏观判断类选题；哲学思考类话题；需要建立「一起探索」氛围的文章

**使用时注意**：困惑要真实，不能是表演出来的困惑；不能困惑太久，要很快进入推导。

---

### O-05｜对比切入

**机制**：展示两种截然不同的状态，用落差制造张力，让读者想知道为什么会有这个差异。

**特征**：A是这样 + B是那样 + 落差制造悬念

**结构**：两种状态 → 这个对比让我思考了什么 → 问题的入口

**示例**：
> 「大学看AI，第一反应是「这会不会让我的专业变得没用」。幼儿园老师们在问的问题，是另一个：有了AI，我怎么让这个孩子成为更好的自己？这一字之差，折射出的是完全不同的教育哲学。」

**适用**：有明显对比对象的选题；需要破除误区的文章；两元对比类框架

**使用时注意**：对比要真实不夸张；两种状态要有结构上的相似性，才能产生有效对比。

---

## 开篇禁忌

- ❌ 「在AI快速发展的今天……」（背景废话，没有张力）
- ❌ 「本文将会探讨……」（这是目录，不是开篇）
- ❌ 「很多人都知道……」（没有把读者放进问题里）
- ❌ 开篇就给结论（破坏了推导的悬念）
- ❌ 开篇引用别人的话作为第一句（读者要看的是你，不是别人）
