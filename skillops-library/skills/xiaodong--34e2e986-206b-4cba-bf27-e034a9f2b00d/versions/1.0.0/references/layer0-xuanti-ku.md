## 一、核心命题方法

核心命题是这篇文章想让读者相信或理解的**那一件事**。用一句话说清楚。

命题不是「这篇文章讲了什么」，而是「这篇文章想让读者相信什么」。前者是目录，后者是灵魂。

### 五种命题类型

| 类型 | 核心问题 | 判断信号 |
|---|---|---|
| 解释现象 | 为什么会发生这件事？ | 读者已感受到现象但不理解原因 |
| 提出判断 | 我认为X是对的，理由是…… | 有一个反常识的核心结论需要论证 |
| 反驳旧观点 | 大家以为是A，其实是B | 存在一个广泛传播但有问题的认知 |
| 给出方法 | 这件事应该怎么做 | 读者有困惑，需要一套可操作的框架 |
| 重新定义概念 | X究竟是什么 | 一个词被误解或被简化，需要重新拆开 |

### 命题质量三问
1. 这个命题，我能用一句话说清楚吗？（说不清 = 命题本身没想透）
2. 这个命题，读者第一反应会是「不对吧」吗？（没有张力 = 缺乏阅读动机）
3. 这个命题，只有我才能论证吗？（别人都能写 = 降低优先级）

## 二、读者对象定义

「略懂AI」的固定读者画像：
- **身份**：中国企业家、高管、高知群体
- **认知位置**：已感受到AI冲击，正在寻找认知坐标
- **真实困惑**：不是「AI是什么」，而是「AI时代我怎么办、我的行业怎么办」
- **阅读动机**：不是学工具，是找框架、找判断、找定心丸

### 每篇文章写前，需要额外确认三件事
1. **他们已经知道什么**：从哪里出发，不要解释已知的
2. **他们真正关心什么**：不是你觉得重要的，是他们的真实问题
3. **他们在哪一步最容易流失**：那里要加强，不能假设他们会跟下去

## 四、选题入库流程

当识别到新选题（来自录音、讲稿、日常思考），按以下格式入库：

```
**[编号]｜[选题名]**
- 命题类型：[五种类型之一]
- 核心命题：[一句话]
- 来源素材：[出处]
- 优先级：[⭐数量]
- 状态：[待写/待补充材料/储备/进行中/已发布]
```

优先级评分标准：
- ⭐⭐⭐⭐⭐：命题清晰 + 有强案例 + 有认知缺口 + 只有邱懿武能写
- ⭐⭐⭐⭐：三项满足
- ⭐⭐⭐：两项满足，需要补充
- ⭐⭐：方向对，但命题还没想透
