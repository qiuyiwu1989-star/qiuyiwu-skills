# 工具五 · 金句库

> 本质：推导链到达关键节点时，张力被压缩成一句话的那个瞬间。不是提前准备好插进去的，是论证完成时自然结晶的。

核心原则：**每篇3-6句，只在论点被完整证明的节点出现。** 金句出现时，读者刚刚完成了一次认知跳跃，金句是对这个跳跃的凝固。

---

## 六种金句构型

| 构型 | 结构 | 判断标准 |
|---|---|---|
| 反转式 | 不是A，而是B（B的含义比A大得多） | 读者第一反应「不对」，想完说「对」 |
| 悖论式 | A和B看起来矛盾，实则是同一件事 | 两种力量同时成立，不可化解 |
| 位移式 | 你以为在讨论X，其实在讨论Y | 读者被挪动到一个新位置 |
| 密度压缩式 | 最少的字承载最完整的推导结论 | 删一字残缺，加一字啰嗦 |
| 追问式 | 提出一个读者必须自己回答的问题 | 无标准答案，但读者无法回避 |
| 时间折叠式 | 把过去/当下/未来放在同一句话里 | 时间跨度制造了句子的纵深 |

## 金句生成流程

写到某个节点，感觉需要金句时，先回答三个问题：

1. **此刻推导链到达了哪个关键节点？**（读者刚刚明白了什么？）
2. **这个节点的核心张力是什么？**（什么和什么在对抗？）
3. **用哪种构型能最精准地凝固这个张力？**（选六种构型之一）

然后生成。生成之后检验：**把这句话单独截图发出去，不读原文，读者能不能感受到它的重量？** 如果不能，说明金句依赖上下文，需要重写。

---

## 金句入库格式

```
### J-XX
**金句**：「……」
**构型**：[六种构型之一]
**适用节点**：[在什么样的论证完成之后出现]
**适用文章**：[适合什么类型的文章]
```
