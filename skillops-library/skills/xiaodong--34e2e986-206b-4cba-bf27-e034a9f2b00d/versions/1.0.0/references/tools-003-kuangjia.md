# 工具三 · 写作框架库

> 本质：决定论证的运动方式——读者被带着走的那条路，是怎么走的。

核心原则：**文章是探索式的，不是论证式的。** 论证式是先亮观点再找例子，框架感重。探索式是先带读者进入现场，跟读者一起「想不通」，一步步接近答案。

---

## 固定骨架：五段推导链

所有文章都走这个骨架，不可跳过，不可随意调换顺序。

```
引入 → 背景 → 分析 → 推演 → 收束
```

| 阶段 | 字数占比 | 核心任务 | 判断标准 |
|---|---|---|---|
| 引入 | 10-15% | 建立问题，不给答案 | 读者读完后在问一个问题，不是收到结论 |
| 背景 | 15-20% | 说明问题为什么现在成立 | 「这不是个人问题，是时代结构问题」 |
| 分析 | 25-30% | 提出核心洞察，揭示问题的真正结构 | 让问题变得更清晰更深，不是给答案 |
| 推演 | 25-30% | 从洞察出发，逐步移动到更大命题 | 每步是前一步的必然结果，不可跳跃 |
| 收束 | 10% | 给读者留一个值得带走的东西 | 不是总结，是余韵，读完还在想 |

**逻辑连贯检验**：把每段的第一句单独拿出来排列，它们应该能连成一条完整的推导链。如果顺序随意调换之后文章仍然成立，说明逻辑不成立。

---

## 五种论证移动方式

在推导链的「推演」阶段，选择一种或组合使用。

---

### F-01｜线性推导

**运动方式**：A→B→C→D，每一步是上一步的必然结果

**逻辑词**：「这意味着」「因此」「顺着这个逻辑」「沿着这条线走下去」

**适用**：一个核心命题需要层层深挖；概念比较抽象需要逐层展开

**示例结构**：
> AI让推理能力的成本趋近于零 → 这意味着推理能力第一次变成了基础设施 → 基础设施改变的不是某个行业，而是所有行业的底层逻辑 → 所以真正的问题不是「AI会替代什么」，而是「什么建立在AI基础设施之上会长出来」

---

### F-02｜现象溯因

**运动方式**：从看得见的现象，追回去找看不见的根因

**逻辑词**：「但问题真的在这里吗」「更深的原因是」「往下挖一层」「这不是表面问题」

**适用**：读者已经感受到问题，但不理解为什么；需要反驳「表面答案」

**示例结构**：
> 幼儿园的AI使用深度超过大学（现象）→ 表面看：幼儿园人少更好推动（浅层原因）→ 但更深的原因是：幼儿园没有「降本增效」的逻辑，它的服务对象不能被工具化（根因）→ 这个根因，才是为什么它能以正确的方式拥抱AI（结论）

---

### F-03｜预期颠覆

**运动方式**：先建立读者的「常识预期」，再打破它，再解释为什么预期是错的

**逻辑词**：「但恰恰相反」「真正的问题不在这里，在」「这里有个被忽视的前提」「我们以为……但实际上」

**适用**：反常识类文章；需要先让读者「上当」再纠正；悖论型命题

**示例结构**：
> 大家都认为AI产品的目标是让用户和AI聊得更爽（建立预期）→ 所以大家都在优化对话体验、提升用户黏性（预期的行动）→ 但我认为这个方向是错的（颠覆）→ 真正有价值的AI产品，是让用户因为AI，和另一个真实的人多聊了几句（新命题）

---

### F-04｜历史类比

**运动方式**：用一个历史事件的结构，映射当下正在发生的事，让陌生的变得熟悉，让当下的显得有分量

**逻辑词**：「这让我想到」「这不是第一次发生」「历史上有一个相似的时刻」「这个结构和XX一模一样」

**适用**：当下的事太新、太难理解；需要给读者一个认知锚点；宏观判断类文章

**示例结构**：
> 1907年西雅图有个送信男孩，从自行车换到摩托车换到汽车，始终做一件事（历史故事）→ 汽车作为基础设施，催生了米其林、麦当劳、沃尔玛，没有一家是做汽车的（历史结论）→ AI作为基础设施，同样的事情正在发生（映射）→ 真正的机会不在AI本身，在它催生的应用层（当下结论）

---

### F-05｜两元对比

**运动方式**：A是这样，B是那样，两者的差异揭示了C（真正重要的那件事）

**逻辑词**：「区别不在于」「真正的差异在」「表面看都是……但」「这两条路的本质不同在于」

**适用**：有明显的误区需要破除，且你有第三种视角；对比类选题

**示例结构**：
> 加AI（给旧系统打补丁）vs AI加（从第一性原理重建）→ 表面看都是在用AI→ 区别在于：谁是主体，谁是工具 → 这个区别，决定了企业在AI时代的最终命运

---

## 推导链规划模板

写正文之前，先填这个模板：

```
核心命题：[一句话]

引入：[用什么场景/数据/问题开场，预计什么时候让读者产生困惑]

背景：[什么历史/时代背景，让这个问题现在成立]

分析：[核心洞察是什么，主线案例要证明什么]

推演：[选择哪种移动方式，从洞察到更大命题分几步，每步说什么]

收束：[留下什么余韵，选哪种结尾方式]
```
