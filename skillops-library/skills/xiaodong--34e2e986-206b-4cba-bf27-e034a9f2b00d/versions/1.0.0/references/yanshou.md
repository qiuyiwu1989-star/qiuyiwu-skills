# 验收系统 · 完稿自动评价

> 这个文件在每次完稿后自动调用，不需要用户提醒。这是写作流程的第九步，也是最后一步。

---

## 验收的本质

验收不是挑错，是检验**认知增量是否真实发生**。

核心问题只有一个：
> **读者读完，世界观里有没有一件事松动了？**

如果答案是「有」，文章成立。
如果答案是「没有」，回到第零层，重新检查核心命题。

---

## 验收评分表

完稿后，按以下七个维度评分，每项0-10分，输出完整验收报告。

---

### V-01｜命题清晰度（0-10）

**评分问题**：核心命题是否在文章中明确成立？读者读完，能不能用一句话说出「这篇文章想让我相信什么」？

| 分值 | 标准 |
|---|---|
| 9-10 | 命题清晰有力，读者无需归纳，自然感受到 |
| 7-8 | 命题能被感受到，但稍需读者自己归纳 |
| 5-6 | 命题模糊，读者读完感觉「说了很多，不知道想说什么」 |
| 0-4 | 文章没有命题，只有信息堆砌 |

---

### V-02｜认知增量（0-10）

**评分问题**：读者读完，有没有一件事是「读之前不知道，读之后知道了」或「读之前这样想，读之后不一样了」？

| 分值 | 标准 |
|---|---|
| 9-10 | 有明确的认知位移，读者世界观里有东西松动了 |
| 7-8 | 有新信息或新角度，但认知位移不够强 |
| 5-6 | 信息正确，但读者早就知道了，换了个说法而已 |
| 0-4 | 旧话换新说，没有真正的增量 |

---

### V-03｜推导链完整性（0-10）

**评分问题**：每段是不是上一段的必然结果？把每段第一句单独拿出来，能不能连成一条逻辑链？

| 分值 | 标准 |
|---|---|
| 9-10 | 逻辑链完整，调换任何一段顺序都会破坏逻辑 |
| 7-8 | 大体成立，有1-2处跳跃需要加强 |
| 5-6 | 有若干段落可以随意调换，逻辑较松散 |
| 0-4 | 段落是并列关系，不是推导关系 |

---

### V-04｜案例服从性（0-10）

**评分问题**：案例有没有「前言」（要证明什么）和「后语」（证明了什么）？案例是不是服务于论点，而不是独立存在？

| 分值 | 标准 |
|---|---|
| 9-10 | 每个案例前后都有明确的论点服务 |
| 7-8 | 大部分案例有服务，个别悬空 |
| 5-6 | 案例存在但悬空，读者不知道它在证明什么 |
| 0-4 | 案例是装饰，不是论证 |

---

### V-05｜金句质量（0-10）

**评分问题**：金句有没有在论点完成的节点出现？数量是否在3-6句之间？每句能否独立成立？

| 分值 | 标准 |
|---|---|
| 9-10 | 3-6句金句，每句在节点处，单独截图有力量 |
| 7-8 | 数量或位置有轻微问题，但整体质量好 |
| 5-6 | 金句位置随机，或数量过多（>6），或依赖上下文 |
| 0-4 | 没有金句，或金句全部是废话加粗 |

---

### V-06｜开篇钩子（0-10）

**评分问题**：前150字有没有让读者感受到「这说的是我」或「我从没想过这个」？开篇是在建立问题，还是在给答案？

| 分值 | 标准 |
|---|---|
| 9-10 | 前150字就建立了强烈问题感，读者被钩住 |
| 7-8 | 开篇有效，但钩子力度中等 |
| 5-6 | 开篇平稳，但没有制造阅读动机 |
| 0-4 | 开篇就给结论，或用背景废话开场 |

---

### V-07｜结尾余韵（0-10）

**评分问题**：结尾有没有给读者留一个值得带走的东西？是余韵还是总结？

| 分值 | 标准 |
|---|---|
| 9-10 | 结尾余韵强，读者读完还在想 |
| 7-8 | 结尾有余韵，但力度一般 |
| 5-6 | 结尾是总结或升华，没有余韵 |
| 0-4 | 总结清单或行动号召，彻底关掉了读者的思考 |

## 分数解读

| 总分 | 判断 | 行动 |
|---|---|---|
| 63-70 | 强文章，可以发布 | 直接发布 |
| 49-62 | 合格，有瑕疵 | 针对最低分维度修改后发布 |
| 35-48 | 需要返工 | 重点修改V-01和V-02，这是根本 |
| 0-34 | 重写 | 回到第零层，重新确认核心命题 |

---

## 验收后的选题库联动

验收完成后，需要做一件事：

**检查有没有新的选题方向在写作过程中生长出来。**

写文章的过程中，经常会产生「这个值得单独写一篇」的感觉。验收报告的最后一行「选题库更新建议」，就是用来捕捉这些的。

捕捉到之后，按 `layer0-xuanti-ku.md` 的入库格式，加进选题储备。
