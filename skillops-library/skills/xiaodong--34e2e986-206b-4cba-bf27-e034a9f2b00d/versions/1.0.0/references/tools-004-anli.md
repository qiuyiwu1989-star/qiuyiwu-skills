# 工具四 · 案例库

> 本质：证明论点的台阶，用完即止。案例不是装饰，不是增加字数的方式。它的存在只有一个理由：证明某个论点。

核心原则：**案例不能单独存在。** 案例之前必须有「这个案例要说明什么规律」，案例之后必须有「它说明了什么」。没有前言和后语，案例是悬空的。

---

## 五种案例角色

| 角色 | 功能 | 篇幅 | 使用规则 |
|---|---|---|---|
| 主线案例 | 承担核心论点的证明 | 400-600字 | 一篇只有1个；前后各有「证什么」「证了什么」 |
| 类比案例 | 把陌生概念映射到读者熟悉的领域 | 50-100字 | 点到即止，用完立刻离开 |
| 佐证案例 | 快速证明「这不是个例」 | 1-2句话 | 可有2-3个，不展开 |
| 反例 | 用「如果不是这样会怎样」来强化论点 | 视情况 | 最有力时机是读者心里刚好产生质疑 |
| 个人案例 | 第一手经历，信任度最高，只有你能写 | 视情况 | 用「我」不用「某人」，细节要真实可验证 |

### K-01｜UPS创始人与汽车革命

**类型**：类比案例 / 主线案例（宏观话题）
**证明什么**：基础设施级别的技术变革，真正产生价值的方式是在应用层，而不是技术本身
**核心内容**：
1907年西雅图，一个送信男孩骑自行车起家，随着交通技术迭代换到摩托车、汽车，始终做一件事：让物品从A到B安全准时到达。他就是UPS的创始人。汽车普及之后，没有一家受益的公司是做汽车的——米其林轮胎、米其林餐厅榜、麦当劳（依托公路网扩张）、沃尔玛（郊区囤货逻辑）、假日酒店（远途出行催生住宿）——都是汽车时代的产物，不是汽车公司。
**收尾金句**：这就是基础设施级别的技术变革，真正产生价值的方式。
**适用文章**：AI基础设施类、宏观判断类、「当IQ变成基础设施」系列

### K-02｜幼儿园AI实践

**类型**：主线案例 / 个人案例
**证明什么**：AI与教育融合的正确打开方式——人在中心，AI扩展人能看到的东西，而不是替代人
**核心内容**：
邱懿武参观某家幼儿园，原以为是AI渗透最慢的地方，结果被震住：用AI分析孩子语言行为数据，追踪表达能力发展轨迹；用摄像头做行为建模，生成个性化成长雷达图；老师用AI读儿童心理学论文，持续更新方法论。出来之后跟园长说：「你们对AI的使用深度，超过了我见过的绝大部分大学。」园长的问题始终是：有了AI，我怎么让这个孩子成为更好的自己？而不是：AI能不能替代老师？
**收尾金句**：一字之差，折射出的是完全不同的教育哲学。
**适用文章**：教育类、AI与人的关系类

### K-03｜初中生龙虾周边案例

**类型**：主线案例 / 个人案例
**证明什么**：AI供给过剩时代，情感连接的稀缺性超越产品质量本身；人为一件东西付钱，永远是因为它和自己或自己在乎的人之间有连接
**核心内容**：
永乐学堂学员，初中生，用AI做了一个虚拟IP形象——一只龙虾。设计水平普通，内部评价中规中矩。但他的周边产品卖得是班里最好的，大几十件。原因：他妈妈属龙，他想给妈妈做一个礼物，设计了「龙虾」（龙和虾的结合）。他带着这只龙虾去他爸爸公司宣传了一圈，同事们不是因为设计好，而是因为「这是他家孩子给他妈妈做的」，纷纷掏了钱。
**收尾金句**：设计价值零分，情感连接价值满分。
**适用文章**：AI创作与商业价值、情感稀缺、IP平台逻辑

### K-04｜小学生 vs 大一新生IP设计

**类型**：对比案例
**证明什么**：被教育的时间越长，固有思维的印记越深；创造力不是被教出来的，而是需要被保护
**核心内容**：
把小学生和大一新生放在一起，同题做IP设计。结果：小学生的作品更有创意、更有网感、更击中人心，说不清哪里好，但「感觉对」。大一新生的作品更规整、更「专业」，但更像某种现有风格的复制。设计师的评价是：小学生的「对」，才是AI时代最稀缺的判断力。
**收尾金句**：被教育的时间越长，固有思维的印记就越深。
**适用文章**：教育类、创造力类、AI时代人才判断

### K-05｜遛狗效应

**类型**：类比案例（老蔡提出）
**证明什么**：宠物是社交入口，不是社交目的；真正好的AI产品，应该让用户因为AI和另一个真实的人多说了几句话
**核心内容**：
两个陌生人在公园擦肩而过，不打招呼。但如果各自牵着狗，两只狗凑到一起，两个人自然产生话题，从聊狗到聊彼此，就认识了。宠物是社交的润滑剂，它降低了人与人连接的摩擦。→ 如果我们做的AI IP是数字世界的宠物，那么它的设计目标不应该是「让用户和AI待得更久」，而是「让用户因为AI，和另一个真实的人产生连接」。
**适用文章**：AI IP平台逻辑、虚拟与真实、社交与孤独

### K-06｜Midjourney遇见中国供应链

**类型**：类比案例 + 佐证案例
**证明什么**：AI创意能力×中国柔性供应链一件起做=一人品牌公司时代到来
**核心内容**：
马斯克找到Midjourney创始人说：你能不能找个中国工厂把Midjourney上的图片做出来？他说如果Midjourney能对接中国供应链，这个世界就完全变了。当时（两三年前）做不到。现在：中国很多布料相关供应链，已经做到一件起做，按需制造。两个变量一叠加，AI创意生成+中国供应链落地=一个人就可以开一个真实的品牌。
**适用文章**：一人公司、IP商业化、数字与实物结合

### K-07｜点了哪几个按钮

**类型**：个人案例
**证明什么**：技术能力通用化之后，「知道怎么用」本身就是护城河；信息传递和社区的价值不会因为AI而消失
**核心内容**：
我们服务一个客户，对方一直在跟进最前沿的AI工具，生产力贼强。有一天来我们这里，看到设计师的操作，问：你效率怎么这么高？最终问的问题是：你那个按钮是怎么点的？点了哪几个按钮？同样的工具，有人就是知道该点哪里，有人不知道。
**适用文章**：上下文护城河、社区与信息传递的价值、AI时代的knowhow

### K-08｜初中生实习50元/天

**类型**：个人案例
**证明什么**：AI时代的人才判断标准在变——管理和金融背景+自学AI做demo的能力，比传统学历路径更有价值
**核心内容**：
暑假请了两个初中生来公司实习，每天给50块钱工资，让他们用AI工具做IP设计。几天后内评，其中一个孩子设计的形象让团队设计师觉得「有点东西」——找不到任何设计专业性的东西，但就是有网感和生命力。设计师们说：感觉对。这个「感觉对」，是AI时代最稀缺的判断力。
**适用文章**：教育类、人才判断类、创造力
