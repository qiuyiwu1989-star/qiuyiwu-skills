## 三、转译规则（传统 → 当代）

### 3.1 形式转译规则

| 转译方向 | 主题处理 | 构成处理 | 色彩处理 | 线条处理 |
|---------|---------|---------|---------|---------|
| 几何化 | 保留母题轮廓 | 骨架网格化 | 单色或限色 | 直线化 |
| 极简化 | 仅保留最小识别特征 | 大幅留白 | 单色/双色 | 极细或极粗 |
| 扁平化 | 保留母题 | 无立体感 | 色块平涂 | 等粗线 |
| 国潮 | 传统母题 | 现代构图混合 | 高饱和中国红/金 | 混合 |
| IP化 | 母题卡通化人格化 | 角色化构图 | 高饱和 | 卡通粗线 |

### 3.2 典型转译案例

**案例1：缠枝莲 → 几何现代**
```
原始：莲花 + 卷草 + 缠枝 + 四方连续 + 唐风华丽
转译：
  主题：保留莲花轮廓
  构成：缠枝 → 几何折线骨架 + 四方连续保留
  色彩：原多色 → 蓝白双色 / 金黑双色
  线条：流动曲线 → 几何直线或弧线
  语义：佛教清净 → 保留；华丽 → 简化
  风格：唐风 → 现代几何
```

**案例2：龙纹 → IP化**
```
原始：龙 + 团花 + 对称 + 明清风 + 权力庄重
转译：
  主题：龙 → 卡通化，保留鳞片/爪子/胡须特征
  构成：对称 → 放松，允许不对称
  色彩：皇家金红 → 彩色/渐变
  线条：工整粗线 → 卡通圆润线
  语义：权力 → 力量/活力；庄重 → 亲切
  风格：明清 → 当代 IP
```

**案例3：梅花 → 极简**
```
原始：梅花 + 折枝 + 留白 + 宋风 + 文人气
转译：
  主题：提取梅花最小识别形（五瓣轮廓）
  构成：极度留白 + 单支
  色彩：单色（黑/朱红/金）
  线条：单线轮廓
  语义：清 + 简 → 极度强化
  风格：宋风极简 → 当代极简
```

## 四、组合验证规则

**使用方法**：在输出设计方案前，用以下规则做最后验证

### 必须检查
- [ ] 主题与语义是否兼容（无高冲突）
- [ ] 构成密度与语义情绪是否匹配（华丽→密；文人→疏）
- [ ] 历史风格与主题是否匹配（唐风→宝相花/缠枝；宋风→折枝/留白）
- [ ] 当代转译是否保留了传统的「语义核心」

### 快速验证公式
```
合理图案 = 主题语义兼容（✓）+ 构成与语义匹配（✓）+ 风格时代一致（✓）
```
