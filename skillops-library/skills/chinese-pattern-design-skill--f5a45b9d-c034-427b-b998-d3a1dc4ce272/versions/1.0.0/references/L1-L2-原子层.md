## 第二维：构成·形（Structure）
> 图案组织的形式语言 · 决定「图案如何长出来」

### 2.1 构成单元
> 最小可重复的图案生长单元

| 单元类型 | 定义 | 适用母题 |
|---------|------|---------|
| 单独纹样 | 独立成件，不重复 | 团花、徽章型 |
| 适合纹样 | 适合于特定外形（圆/方/角） | 团花、扇形图案 |
| 团花 | 圆形放射对称 | 花卉、龙凤 |
| 缠枝 | 以藤蔓为骨架延伸 | 植物类 |
| 折枝 | 截取自然枝干一段 | 花鸟画风格 |
| 角隅纹样 | 填充角落 | 几何 + 植物 |

### 2.2 连续方式
> 如何从单元延伸到无限

| 方式 | 定义 | 典型应用 |
|-----|------|---------|
| 二方连续 | 上下或左右方向无限延伸 | 边饰 · 腰带 · 边框 |
| 四方连续 | 上下左右均可延伸 | 织物地纹 · 壁纸 |
| 散点式 | 单元散布，无固定连续 | 撒花纹 |
| 满地式 | 密集铺满整个底面 | 高档织物 |
| 环形连续 | 沿环形排列 | 圆形器物腹部 |
| 菱形骨架 | 以菱形为骨架单元填充 | 织锦 |

### 2.3 布局方式
> 空间秩序与视觉重心的建立

| 布局方式 | 特征 | 中国美学含义 |
|---------|------|------------|
| 对称 | 中轴镜像 | 礼制秩序 · 天地和合 |
| 均衡 | 视觉重量平衡但不镜像 | 气的流动 |
| 放射 | 从中心向外发散 | 中心意识 · 太阳崇拜 |
| 中轴 | 强调垂直中心线 | 皇权 · 正统 |
| 自由 | 无固定规律 | 文人自然观 · 写意 |
| 环形 | 沿圆周排列 | 圆满 · 循环 |
| 对角线 | 沿对角线布局 | 动势 · 现代感 |

### 2.4 空间结构
> 虚与实·平面与深度

| 空间类型 | 特征 | 美学效果 |
|---------|------|---------|
| 平面展开 | 无前后层次 | 装饰性强 · 秩序感 |
| 层叠空间 | 有明显前后层次 | 丰富 · 立体 |
| 深空间透视 | 模拟三维纵深 | 叙事性强 |
| 留白结构 | 大面积留白为主 | 禅意 · 空灵 · 文人气 |
| 满铺结构 | 几乎没有空白 | 华丽 · 富贵 · 宫廷感 |
| 开光结构 | 以框形划分主题区域 | 叙事 · 强调主题 |

### 2.5 线条语言
> 图案的笔意质感

| 线条类型 | 特征 | 对应风格 |
|---------|------|---------|
| 工整匀称线 | 粗细一致 · 圆润流畅 | 宫廷 · 工艺 |
| 流动曲线 | 有节奏变化 · 自然 | 花鸟 · 卷草 |
| 书写性线条 | 有明显提按顿挫 | 文人水墨 |
| 装饰性线条 | 图案化 · 风格化 | 各类工艺装饰 |
| 几何硬线 | 直线 · 折线 · 锐角 | 几何纹 · 当代转译 |

### 2.6 节奏与密度
> 视觉节拍的控制

| 节奏类型 | 视觉效果 | 适用场景 |
|---------|---------|---------|
| 均匀重复 | 稳定 · 沉静 | 边饰 · 底纹 |
| 渐变推移 | 流动 · 变化 | 过渡区域 |
| 疏密对比 | 呼吸感 · 文人气 | 折枝 · 写意 |
| 呼应关系 | 对话感 · 平衡 | 双面构图 |
| 强对比 | 张力 · 戏剧感 | 现代转译 |
| 镜像对称 | 完整 · 庄重 | 门扇 · 开光 |
