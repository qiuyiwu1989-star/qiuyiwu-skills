## 案例 01：缠枝莲纹

```
主题·象：植物纹 → 莲花 + 卷草
构成·形：缠枝 + 四方连续 + 均衡 + 流动曲线 + 中高密度
语义·意：佛教清净 + 吉祥 + 生生不息（宇宙观）
风格·气：唐风 + 东方古典 + 富丽华美
```

**提示词参考**：
中文：莲花 卷草 缠枝 四方连续 唐风 华丽对称 中国装饰图案 金线勾勒  
English: lotus motif, arabesque vine, Tang dynasty ornamental, symmetric floral pattern, gold outline, rich decorative

## 案例 02：宝相花纹

```
主题·象：植物纹 → 莲花 + 牡丹 + 卷草（复合母题）
构成·形：团花 + 单独纹样 / 适合纹样 + 放射对称 + 圆润工整线 + 满密
语义·意：佛教庄严 + 富贵圆满 + 皇家华丽
风格·气：唐风 + 富丽华美 + 装饰繁复
```

**文化说明**：宝相花是唐代最具代表性的装饰纹样，莲花+牡丹+卷草的复合构成，
象征佛教与皇家美学的融合，是"有中国味"的典型示例之一。

## 案例 03：梅花折枝纹（文人版）

```
主题·象：植物纹 → 梅花（单枝/折枝）
构成·形：折枝 + 单独纹样 + 自由布局 + 大留白 + 书写性线条 + 极疏
语义·意：文人精神（清·孤·雅）+ 岁寒三友 + 宁静
风格·气：宋风 + 文人气 + 禅意留白
```

**设计要点**：梅花文人版的关键是「留白大于图案」，线条必须有书写感，不可工整匀称。
如果线条太圆润，会失去文人气。

## 案例 04：回纹边饰

```
主题·象：几何抽象纹 → 回纹
构成·形：二方连续 + 几何线 + 均匀重复 + 对称 + 中高密度
语义·意：循环往复（宇宙观）+ 富贵不断头（吉祥寓意）
风格·气：商周至明清（跨朝代通用）+ 庄重典雅
```

**使用说明**：回纹是最常用的边饰纹样之一，作为主体纹的边框使用时，
选择密度与主体协调（主体文人气→回纹稀疏；主体华丽→回纹密集）。

## 案例 05：龙纹（宫廷版）

```
主题·象：动物纹 → 龙（五爪正龙）
构成·形：团花 + 单独纹样 + 对称中轴 + 工整粗线 + 满密
语义·意：皇家权力 + 天命 + 阳气 + 庄重威严
风格·气：明清风 + 庄重典雅 + 东方古典
```

**禁用组合**：五爪正龙 ✗ 极简/文人气/现代风，会产生严重的语义冲突。
若现代使用，建议改为游龙/草龙，弱化权威感。

## 案例 06：鹤纹（道教文人版）

```
主题·象：动物纹 → 鹤（双鹤 / 松鹤）
构成·形：折枝式 + 均衡 + 自由布局 + 流动曲线 + 疏
语义·意：道教长生 + 文人清雅 + 长寿
风格·气：唐至宋风 + 清雅克制 + 文人气
```

**常见搭配**：鹤 + 松（岁寒长寿）、鹤 + 云（仙境飞升）、鹤 + 菊（高洁长寿）

## 案例 07：海水江崖纹

```
主题·象：自然景物纹 → 海水纹 + 山石
构成·形：适合纹样（底摆位置）+ 均衡 + 工整装饰线 + 中高密度
语义·意：皇家专属 + 江山永固 + 天下一统 + 庄重
风格·气：清风 + 庄重典雅 + 礼制秩序
```

**使用场景**：官服补子、龙袍下摆——高度礼制化，非宫廷 / 官员场景不建议直接使用，
当代使用建议保留水波部分，弱化礼制语义。

## 案例 09：四君子纹（文人器物版）

```
主题·象：植物纹 → 梅花 + 兰花 + 竹 + 菊（四君子组合）
构成·形：折枝 + 单独纹样组合 + 自由均衡 + 书写性线条 + 疏密对比
语义·意：文人精神（清·雅·静·逸）+ 高洁 + 君子人格
风格·气：宋元文人气 + 禅意 + 清雅克制
```

**设计逻辑**：四君子通常不作四方连续，而是以一件器物四个面分别表现，或四元素自由组合。
高度留白是必要条件。

## 案例 10：缠枝莲纹（国潮转译版）

```
主题·象：植物纹 → 莲花（几何化轮廓）+ 卷草（简化线条）
构成·形：缠枝骨架保留 + 几何化 + 扁平化 + 高对比色块
语义·意：吉祥 + 生生不息（语义骨架保留）
风格·气：当代表达 → 国潮融合 + 几何化
```

**转译操作记录**：
- 莲花从写实 → 几何化五瓣 / 莲蓬形
- 卷草从流动曲线 → 几何折线或规则弧线
- 色彩从多色渐变 → 限色平涂（红/金/白 或 青/白）
- 保留四方连续骨架
- 语义：华丽削减，吉祥保留
