# 推理策略手册
## 六种意图识别与推理路径

---

## 策略 A：母题扩散推理
**触发**：用户给出具体纹样名称（"龙纹"/"梅花"/"回纹"）

**推理步骤**：
1. 确认母题在哪个 L2 分类下
2. 从 L1-L2-原子层.md 中调取该母题的完整信息
3. 推导常见语义组合（从语义层检索关联标签）
4. 推导最自然的构成方式
5. 给出 2-3 种风格可能（不同时代/气质的版本）
6. 询问用户倾向，或直接输出最典型版本

**示例**：
```
用户：帮我设计一个龙纹
→ 主题：动物纹 · 龙（权力·天命·阳气）
→ 语义推荐：庄重 + 皇家威严 / 或 国潮豪迈
→ 构成推荐：团花对称 / 或 满密布局
→ 风格选项：① 明清宫廷风 ② 汉风古朴 ③ 国潮现代
→ 询问：您希望是传统庄重感，还是现代感更强？
```

## 策略 B：语义-风格反推
**触发**：用户描述感受/氛围（"我想要清冷文人气"/"要很空灵的感觉"）

**推理步骤**：
1. 从语义层识别情绪氛围标签（庄重/空灵/宁静/灵动/华丽/热烈/典雅/古朴）
2. 识别文人精神标签（清/雅/静/远/简/逸）
3. 反推适合的主题母题（语义→主题关联规则）
4. 反推适合的构成方式（语义→构成关联规则）
5. 确定风格（语义+主题→风格对应）
6. 输出完整设计卡

**语义-主题关联规则**：
| 感受词 | 推荐主题 | 禁用主题 |
|-------|---------|---------|
| 清冷 / 文人 | 梅、竹、兰、菊、山石 | 牡丹、石榴、婴戏 |
| 空灵 / 禅意 | 莲、云、竹、留白构成 | 龙凤、满密纹 |
| 华丽 / 富贵 | 牡丹、宝相花、龙凤 | 梅、竹、简约纹 |
| 庄重 / 威严 | 龙、凤、海水江崖、回纹 | 蝴蝶、婴戏、散点花 |
| 灵动 / 活泼 | 蝴蝶、鱼、折枝花鸟 | 庄重几何纹 |
| 宁静 / 古朴 | 山石、松竹、云气 | 喜庆纹样 |

## 策略 C：图像解析识别（多模态）
**触发**：用户上传包含中国图案的图片

**解析步骤**（四维逐层）：
1. **主题识别**：这个图案的视觉母题是什么？归属哪个 L2？
2. **构成分析**：用了什么构成单元？连续方式？布局逻辑？线条语言？
3. **语义判断**：承载了什么文化语义？哪个语义子系统？
4. **风格判断**：整体气韵属于哪个朝代风格 + 审美气质？

**输出格式**：
```
【图案解析报告】
✦ 主题：[L2分类] · [具体母题]
✦ 构成：[构成单元] + [布局方式] + [线条特征]
✦ 语义：[语义系统] · [核心寓意]
✦ 风格：[历史风格] + [审美气质]
✦ 文化背景：[1-2句文化解读]
```

## 策略 D：风格基因反推
**触发**：用户指定历史风格（"帮我做唐风图案"/"宋风感觉"）

**反推逻辑**：
```
风格输入 → 调取对应朝代特征 → 推荐母题组合 → 推荐构成方式 → 推荐语义标签
```

**各朝代推荐组合速查**：

| 风格 | 推荐主题 | 推荐构成 | 标志性语义 |
|-----|---------|---------|----------|
| 商周风 | 饕餮、云雷、龙凤 | 对称、满密、几何线 | 神圣 · 威严 · 原始力 |
| 汉风 | 云气、四神、博古 | 流动、铺张、曲线 | 豪迈 · 生命力 |
| 唐风 | 宝相花、缠枝莲、凤鸟 | 团花、缠枝、满密、流动线 | 华丽 · 包容 · 宏大 |
| 宋风 | 梅兰竹菊、折枝花鸟 | 折枝、留白、疏密对比 | 清雅 · 文人气 · 简约 |
| 明清风 | 百花、龙凤、吉祥纹 | 满密、精工、多色 | 繁丽 · 吉祥 · 精工 |
| 敦煌风 | 飞天、莲花、忍冬 | 放射、环形、满密 | 神圣 · 西域融合 |

## 策略 E：全维度结构化编译（完整意图）
**触发**：用户提供完整需求（场景+用途+感受+风格限定）

**编译步骤**：
1. 解析用户意图，提取四维输入信息
2. 逐维确认（不确定的维度询问补充）
3. 用关系规则引擎验证组合的合理性
4. 生成完整「中国图案设计卡」
5. 输出 AI 生成提示词

---

## 策略 F：图案解构与学术分析
**触发**：用户问「这个纹样是什么」「这个图案有什么含义」「为什么是这个设计」

**分析框架**：
1. 命名 + 归类（属于哪个 L1/L2）
2. 历史溯源（起源朝代 + 演变）
3. 文化语义（承载什么意义，出自哪个文化系统）
4. 构成分析（用了什么形式语言）
5. 应用场景（历史上常用于什么器物/服饰/建筑）
6. 当代传承（现在怎么用，有哪些转译版本）
