## 使用说明

1. 复制上面的模板
2. 按实际情况填写每个模块
3. 不需要的模块删掉（比如没有scripts就不写）
4. 跑一遍质量检查清单确认交付质量
5. 如果是新Agent，同步更新：
   - `memory/team-roster.md` — 加花名册条目
   - `skills/founder/SKILL.md` — 加spawn模板
   - `MEMORY.md` — 团队架构区加条目
