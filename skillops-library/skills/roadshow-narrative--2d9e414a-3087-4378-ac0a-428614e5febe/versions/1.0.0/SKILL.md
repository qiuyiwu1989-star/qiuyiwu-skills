# roadshow-narrative：路演 / 叙事方法论

**心法一句话**：
> **叙事不是"把产品讲清楚"，是"让别人相信你、并且帮他完成他要完成的一件事"。**

邱懿武原话：「路演的本质**不是把产品讲清楚**……是让别人**相信你**、觉得你能把这件事做成。」
2015 云栖小镇复盘：「**你不是在路演产品，而是在帮助他完成一件他的事情。**」

> 边界（务必同时记住）：**故事负责让人相信、让人看见机会；它不能替你把"这事成立"证明掉。** 叙事一旦跑在证据前面，就是风险。（见文末"反方"）

---

## 一、先问四句（对谁讲）

写作前必须回答这四问：

| 问 | 说明 |
|---|---|
| 我要跟这群人**讲什么故事**？ | 故事是承载整个项目最好的**载体** |
| **打动的人**到底是谁？ | 决策者？把关者？还是他的上级？ |
| 他**希望听到什么**？ | 站在他的立场 |
| 我想让他**给我什么**？ | 钱？资源？批注？转发？ |

> 「就像销售一样，路演本质也是销售。」——先想清楚要什么，再决定讲什么。

## 二、按对象换故事（四类）

| 对象 | 他真正在意 | 你的故事重点 |
|------|-----------|-------------|
| **投资人** | 这是不是**值得下注**的事 | 为什么做、规模、真需求、壁垒、能不能做成 |
| **客户 / 上下游** | 你**靠不靠谱**、能不能解决我**具体**的问题 | 解决了什么、带来什么价值、路径、风险与打消顾虑 |
| **渠道 / 伙伴** | 一起干、**怎么分钱、能赚多少** | 大家一起干、分账逻辑、盘子多大 |
| **内部** | 对齐**共识** | 逻辑、背后资源、目标达成路径 |

> 同一件事，对不同人讲不同的故事。**别用一套稿打所有人。**

## 三、九页骨架（"颠覆性思维"，适合早期 / 理念创新型）

| # | 页 | 干什么 | 要点 |
|---|----|-------|------|
| 1 | **描述现状** | 拉近共识 | 现在是什么市场/行业、大家都怎么干、成规旧律是什么 |
| 2 | **深度洞察** | 说出别人没说出的规律 | 例：王坚看电瓶车"都用公模"→注定结果一样 |
| 3 | **代入感故事** | 让人有切身体验 | 必须**有"人"作主体**（背景/叙事/结果/情绪起伏），否则退化成理论陈述 |
| 4 | **差异化观点** | "你看到了不一样的事" | 加强印象，让他形成自己对该项目的判断 |
| 5 | **类比 / 广告语** | 场景代入 | "电动车里的特斯拉"；"面粉·面条·面包" |
| 6 | **产品方案** | **本质是获取信任** | 不是介绍功能——"我不可能只拿一张效果图，我真的把车拿出来" |
| 7 | **描绘美好图景** | 改变后的生活/工作 | "饼画完了，还要画饼吃饱后的样子" |
| 8 | **展望社会价值** | 前后呼应 | 这种改变对社会的价值 |
| 9 | **收束** | 逻辑调一调、讲透 | — |

**生产方式**：按顺序写成一版 → **让 AI 生成多版** → 逐版确认。

## 四、三个最狠的抓手

1. **第一页定生死**——一句话讲清："**我为谁创造什么价值、通过什么方式、是一家怎样的公司**"。"第一页没镇住场，他就在划水了。"
2. **抛真问题**——"他没听过、能勾起好奇的问题"（"中国电动车 3000 万台，很多着火"）。真问题一出，聪明人会**自己帮你脑补**。
3. **用一个类比**——最不依赖专业背景、最容易迁移的动作。全片至少给一个记忆锚点。

## 五、两套方法，别混用

| 方法 | 适合 | 特征 |
|------|------|------|
| **颠覆性思维九页** | 早期 / 理念创新型 | 突破性、颠覆性、讲故事拿认可 |
| **红杉经典商业 BP** | 硬科技 / 专家对专家 / 体制内 | 结构严谨、数据与尽调经得起追问 |

> 邱懿武自陈：靠"讲故事"前面几轮融资特别容易；**过了 A/B 轮就要靠 FA**（财务尽调要的是细分问题的答复，不是故事）。

**体制内的额外要求**：要讲**响应的政策**（体制内比市场化更看重政策口径）。

## 六、反方（写在方法论里，别丢）

- **叙事经济学成立，但两面**：先有故事 → 形成共识 → 带动增长（邱懿武引诺奖研究）。**但故事跑在证据前面，就是风险。**
- **类比越顺，越可能掩护难点**：深脑分析（方法#047）指出，"面粉·面条·面包"让全场"听懂了**结构**"，却绕过了"从自产到外购、用完还要复购"这个**没跑通的闭环**。
- **最硬的那句（能不能做成）留给证据，别留给叙事。**

---

## 用法

1. 用户要写路演/汇报/对外演讲 → 先问**四问**，再定位**对象类型**；
2. 选**九页**（早期/理念）或**红杉 BP**（硬科技/体制内）骨架；
3. 逐页写一版 → **让 AI 生成多版对照** → 逐版确认；
4. 检查：第一页有没有镇场？有没有一个真问题？有没有一个类比？故事那页有没有"人"？最硬的那句有没有证据？
