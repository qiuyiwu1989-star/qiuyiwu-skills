# slide-style-router

先识别听众、目标、阅读方式、信息密度和必须保留条件。按硬要求排除不适合的风格，再比较表达任务、情绪、视觉机制与偏好。读取项目风格标签档案；标签是建议不是证据。优先推荐有相关验证样页的风格，对未验证能力明确不确定性。给2至3候选及适用理由和取舍；用户已选择则不重新选风格。必要时先试一页。禁止仅按主题关键词匹配，禁止把风格推荐变成固定构图推荐。

同一内容可以有不同讲法。先判断听众适合从故事、具体动作、对比、证据还是关系进入，再匹配视觉风格。例如同一道应用题，故事讲法可以借角色的选择解释数量关系，公式讲法可以直接展示等量关系。风格标签应说明能支持什么讲法和密度，并指向具体样页；页型是选择工具，不能预先锁定构图。
