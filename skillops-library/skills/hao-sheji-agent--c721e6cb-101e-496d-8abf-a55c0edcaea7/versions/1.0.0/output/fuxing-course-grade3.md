# 复兴号课程 · 小学三年级

**适用年级**：小学三年级（8-9岁）
**课时时长**：40-45分钟（1课时）
**跨学科连接**：科学、数学、道德与法治、美术

---

## 一、导入（5分钟）

**开场问题**：
> "如果有一列火车，每小时能跑350公里——从北京到上海只需要4个多小时。你们觉得，这么快的火车，为什么不会飞出去？"

**类比引入**：
> "高铁每小时350公里，相当于一直被12级台风吹着跑，但它稳稳地趴在轨道上。它是怎么做到的？"

---

## 二、核心知识点（15分钟）

### 🔍 秘密一：中国高铁的"进化史"（3分钟）

| 阶段 | 就像…… | 特点 |
|------|--------|------|
| **和谐号** | 穿别人的衣服 | 买了好几个国家的技术，合在一起 |
| **复兴号** | 自己量身定做了一套 | 84%是中国自己定的标准，完全自主 |

### 🔍 秘密二：为什么飞不出去？（5分钟）

1. **超重的身体**：约500吨（≈100头大象骑在一起），越重越稳
2. **空气动力外形**：车头流线型，让风"滑过去"而不是"撞上来"
3. **自动"刹车王"**：1000多组传感器，像人的"神经末梢"

### 🔍 秘密三：从"学别人"到"别人来学"（7分钟）

```
2004年 → 买了国外技术（穿别人的衣服）
2008年 → 开始自己研究（量尺寸）
2010年 → 造出和谐号（试穿）
2017年 → 复兴号上线！（自己设计的衣服！）
现在  → 中国高铁卖到了全世界 🌍
```

---

## 三、课堂探究（10分钟）

### 基础问题：
1. "复兴号和和谐号最大的区别是什么？"
2. "如果你坐在复兴号上，手里拿一杯水，水会洒出来吗？为什么？"

### 开放讨论：
3. "如果你是中国高铁工程师，你觉得接下来应该让高铁做到什么？"
4. "生活中还有什么东西，是先学别人的、后来变成自己的？"

### 动手活动：
> 每人发一张A4纸，折一个"复兴号车头"。比谁的飞得远、飞得稳。

---

## 四、总结（5分钟）

**三句话带走**：
1. 复兴号是中国完全自主设计的高速列车，84%用的是中国标准
2. 它能跑350公里/小时还不飞出去，靠的是重力、空气动力学和智能感知
3. 最重要的一课：从学到创，是每个好设计都要走的路

**留下一个"开口"**：
> "今天回家，可以问问爸爸妈妈：你小时候坐的火车有多快？"

---

## 五、教师注意事项

| 潜在难点 | 应对方式 |
|---------|---------|
| "350公里/小时"太抽象 | 换成"你家汽车在高速上开120，它比汽车快3倍" |
| "自主创新"概念太抽象 | 用"穿别人的衣服→自己做衣服"的比喻 |
| 学生注意力分散 | 每5分钟切换一次形式（听→答→动手→看图） |
| 不要堆数据 | 三年级记住"350公里""12级台风""13年"三个数字就够了 |
