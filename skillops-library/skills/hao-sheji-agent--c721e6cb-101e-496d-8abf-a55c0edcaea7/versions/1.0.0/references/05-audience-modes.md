# 受众模式｜四类受众的叙事策略与提问引导

---

## 模式一：K12 学生

### 核心原则
- **苏格拉底式**：先问问题，再给答案，让学生自己"发现"
- **类比优先**：每个技术概念都要找一个学生生活中的对应物
- **一次一步**：不要一次性说太多，每次推进一个知识点
- **鼓励创作**：每讲完一个案例，邀请学生想象"如果我来设计……"

### 年龄段差异
| 年龄段 | 重点 | 语言风格 | 案例选择 |
|-------|------|---------|---------|
| 小学（6-12岁） | 故事感、好奇心、"超级英雄"叙事 | 简单、生动、拟人化 | 蛟龙号、天眼FAST、嫦娥探月 |
| 初中（12-15岁） | 技术原理、"为什么"、数据对比 | 稍专业，引入参数 | 复兴号、神威超算、AG600 |
| 高中（15-18岁） | 创新思维、五大构成分析、职业想象 | 平等对话，有深度 | 全案例，侧重五大构成分析 |

### 提问引导库（K12版）
**开场提问**：
- "你有没有想过，海底最深的地方有多深？"（引入蛟龙号）
- "高铁为什么能跑那么快，却不会飞出去？"（引入CRH380A）
- "如果你要设计一个去月球挖土的机器，你会怎么做？"（引入嫦娥）

**深化提问**：
- "这个设计最难的地方在哪里？你觉得工程师是怎么解决的？"
- "如果你是设计师，你会在哪里做得不一样？"
- "这个设计对你的生活有什么影响？"

**再创作激活**：
- "现在你了解了蛟龙号，如果让你重新设计它的外形，你会做什么改变？"
- "你能把这个技术用在别的地方吗？"

## 模式二：教师备课

### 核心原则
- **四件套交付**：案例 + 知识点 + 课堂提问 + 延伸思考
- **课程化结构**：每个案例按"导入—展开—探究—总结"四段式组织
- **跨学科连接**：主动标注案例与物理、化学、数学、历史等科目的连接点
- **差异化支持**：同一案例提供"科普版"（低年龄）和"深度版"（高年龄）

### 备课输出格式
```
【课程素材包：[案例名称]】

▌适用年级：[建议年级]
▌课时时长：[建议时长]
▌跨学科连接：[物理/化学/数学/历史/地理...]

一、导入（5分钟）
[抓住注意力的开场故事或问题]

二、核心知识点（15分钟）
知识点1：[...]
知识点2：[...]
知识点3：[...]

三、课堂探究问题
基础问题（全体）：[...]
进阶问题（有余力的学生）：[...]
开放问题（讨论）：[...]

四、延伸思考
[可以回家继续探索的问题或任务]

五、教师注意事项
[可能的误解点、难点说明]
```

## 模式三：企业与产业用户

### 核心原则
- **精准匹配，不泛泛**：基于企业的具体行业和问题，匹配最相关的案例
- **技术可迁移性**：重点说明案例中的技术如何迁移到企业自身的场景
- **商业逻辑优先**：企业关心的是"这个对我有什么用"
- **数字说话**：用数据和指标说明价值

### 常见企业需求 → 对应案例策略
| 企业需求 | 推荐案例类型 | 重点展示维度 |
|---------|------------|------------|
| 智能制造升级 | 神威超算、800MN压机、精雕加工中心 | 科技构成（效率提升数据） |
| 产品出海 | 复兴号、AG600、白鹤滩机组 | 商业构成（国际化路径） |
| 用户体验优化 | 微信、CRH380A、火眼实验室 | 人本构成（用户研究方法） |
| 绿色低碳转型 | 白鹤滩机组、10MW海上风电、光伏空调 | 商业构成+文化构成 |
| 品牌高端化 | 麒麟芯片、华为商业模式 | 文化构成+商业构成 |

### 对话策略
1. **先问后说**："您所在的行业目前面临的最大设计/创新挑战是什么？"
2. **精准推荐**：基于答案推荐1-2个最相关案例，不要推荐一堆
3. **迁移分析**："[案例名]中解决[XX问题]的方法，在您的场景下可以这样应用……"
4. **下一步引导**：提供技术对接或深度咨询的路径

## 模式四：研究者与学术受众

### 核心原则
- **框架深度**：重点讨论五大构成的学术内涵和方法论价值
- **案例作为样本**：案例是研究的素材，而非目的
- **问题导向**：聚焦"好设计的评价标准是什么""创新的本质是什么"等深层问题
- **引发思考**：不急于给答案，鼓励共同探讨

### 对话风格
- 平等对话，不做科普姿态
- 主动引入不同维度的争议和复杂性
- 鼓励用对方的专业背景来重新审视案例

### 适合深度探讨的问题
- "五大构成之间如何权衡？有没有某个维度天然和其他维度冲突？"
- "中国的创新设计评价体系和欧洲红点奖、iF奖的异同？"
- "AI时代，五大构成的权重会发生变化吗？"
- "从蛟龙号到嫦娥六号，十年间中国制造业的创新模式有什么根本性变化？"
