# 五大构成｜理论框架与专业标识词典

> 五大构成——艺术构成、人本构成、科技构成、商业构成、文化构成——是浙江大学创新设计学科多年研究与实践的结晶，也是「好设计」创新馆的认知操作系统。每个案例都应从这五个维度被理解、被分析、被迁移。

---

## 五大构成总览

| 构成维度 | 核心关切 | 分析的核心问题 | AI能力对应 |
|---------|---------|------------|----------|
| **科技构成** | 技术原理、材料、工艺、性能 | 这个设计突破了什么技术难题？ | 技术理解、场景迁移、方案生成 |
| **艺术构成** | 造型、色彩、材质、视觉语言 | 这个设计的美在哪里？如何引发情感共鸣？ | 风格生成、视觉方案推荐 |
| **人本构成** | 用户体验、交互、情感设计 | 这个设计为谁服务？如何理解人的真实需求？ | 需求理解、体验设计辅助 |
| **商业构成** | 商业模式、市场逻辑、价值链 | 这个设计如何创造经济价值？能复制吗？ | 商业可行性分析、转化策略 |
| **文化构成** | 文化语境、符号意义、在地性 | 这个设计在什么文化背景下有意义？ | 文化调性分析、本土化建议 |

---

## 一、科技构成

### 核心关切
技术突破是好设计的底层支撑。科技构成关注：材料创新、工艺突破、系统集成、性能提升、自主可控。

### 专业标识词典
**技术路径类**：自主研发 / 集成创新 / 原创突破 / 进口替代 / 卡脖子攻克 / 首创技术 / 世界纪录
**材料工艺类**：钛合金 / 高温合金 / 碳纤维复合材料 / 精密铸造 / 激光增材制造 / 超精密加工
**系统能力类**：冗余设计 / 多轴协同 / 智能感知 / 自适应控制 / 全链条自主 / 数字孪生
**性能指标类**：精度达到xx毫米 / 效率提升xx% / 能耗降低xx% / 使用寿命xx年

### 分析框架（用于案例标注）
1. **技术突破点**：突破了什么具体的技术难题？
2. **自主化程度**：核心部件国产化率是多少？
3. **性能指标**：关键参数达到什么水平？和国际对标如何？
4. **可迁移性**：核心技术可以迁移到哪些其他场景？

### 代表性案例
- 蛟龙号：高速数字水声通信、7000米全海深耐压结构
- 神威·太湖之光：100%国产申威处理器、千万核并行
- 800MN模锻压机：全球最大、预应力钢丝缠绕结构

## 二、艺术构成

### 核心关切
好的设计不只有功能，还有美。艺术构成关注：造型语言、色彩系统、材质美学、视觉传达、情感体验。潘院士特别强调："画画一定要有诗意"——创新设计也需要诗意。

### 专业标识词典
**造型类**：流线型 / 仿生造型 / 模块化形态 / 人体工学形态 / 极简主义
**色彩类**：功能性配色 / 品牌识别色 / 安全警示色 / 文化象征色
**材质类**：质感设计 / 金属光泽 / 哑光处理 / 复合材质搭配
**视觉语言类**：中国美学元素 / 科技感 / 未来感 / 工业美学 / 自然仿生

### 分析框架
1. **造型逻辑**：造型从哪里来？功能驱动还是美学驱动？
2. **视觉识别度**：这个设计一眼能认出来吗？
3. **情感唤起**：看到它，你第一感觉是什么？
4. **文化审美**：有没有融入中国文化的审美基因？

### 代表性案例
- CRH380A：12米流线头型，中国高铁视觉语言的奠基
- 翼型风帆助推原油船：帆的诗意与现代工业美学的融合
- 蛟龙号：红白配色的大国深海探索者形象

## 三、人本构成

### 核心关切
设计为人服务。人本构成关注：用户需求洞察、使用体验、无障碍设计、安全性、情感连接。

### 专业标识词典
**需求层次类**：基本功能需求 / 安全需求 / 舒适需求 / 情感需求 / 自我实现需求
**体验维度类**：易用性 / 可达性 / 可靠性 / 舒适度 / 噪声控制 / 空间感
**用户群体类**：全年龄段覆盖 / 老人友好 / 儿童安全 / 无障碍设计 / 专业用户
**情感设计类**：信任感 / 安全感 / 愉悦感 / 仪式感 / 归属感

### 分析框架
1. **核心用户**：谁在用这个设计？他们的真实痛点是什么？
2. **体验改善**：和之前的方案相比，用户体验提升了什么？
3. **极端场景**：在最恶劣的条件下，用户还能安全使用吗？
4. **情感价值**：这个设计除了功能，还给用户带来了什么感受？

### 代表性案例
- 复兴号：座椅间距增大、全车WiFi、噪声降低至"轻声交谈"级
- 微信：极简设计覆盖全年龄层，从青少年到中老年
- AG600：浪高2米海况下稳定起降，给救援队员的安全保障

## 四、商业构成

### 核心关切
好设计要能创造价值、可以被复制和传播。商业构成关注：商业模式创新、市场逻辑、价值链重构、规模化路径、生态构建。

### 专业标识词典
**商业模式类**：平台模式 / 生态模式 / 订阅制 / 服务化转型 / 产业链整合
**市场价值类**：市场规模 / 国产替代 / 出口潜力 / 行业标准制定 / 定价权
**产业影响类**：带动上下游 / 产业集群 / 就业创造 / 区域经济 / 外溢效应
**增长逻辑类**：网络效应 / 飞轮效应 / 数据驱动 / 规模经济 / 品牌溢价

### 分析框架
1. **价值创造**：这个设计创造了多少经济价值？能量化吗？
2. **商业模式**：它如何持续赚钱？有没有可复制的逻辑？
3. **产业带动**：它带动了多少上下游产业？
4. **国际竞争力**：它在全球市场上的定价权和话语权如何？

### 代表性案例
- 微信：小程序年交易额超10万亿，移动互联网生态闭环
- 复兴号：中国高铁标准输出，雅万高铁等海外项目的基础
- 白鹤滩机组：年均发电量624亿千瓦时，西电东送骨干电源

## 五、文化构成

### 核心关切
设计在文化语境中才有完整意义。文化构成关注：文化符号、国家叙事、在地性、时代精神、文化传播。

### 专业标识词典
**国家叙事类**：大国重器 / 国之重器 / 中国创造 / 自主可控 / 民族复兴
**文化符号类**：中国美学 / 传统文化转化 / 东方设计基因 / 文化自信
**时代精神类**：工匠精神 / 科技报国 / 创新驱动 / 开放合作
**传播影响类**：科普标杆 / 教科书级别 / 进馆收藏 / 国际影响力

### 分析框架
1. **文化意义**：这个设计在中国文化语境下代表什么？
2. **时代价值**：它为什么在这个时代特别重要？
3. **符号功能**：它有没有成为某种文化符号或集体记忆？
4. **传播潜力**：它的故事能打动什么样的人？用什么方式讲？

### 代表性案例
- 蛟龙号：从"跟跑"到"领跑"的深海探索精神
- 嫦娥五/六号：人类首次月球背面采样，中国探月的文化高峰
- 神威·太湖之光：完全自主可控，中国科技自立自强的旗帜

## 五大构成分析输出模板

分析一个案例时，建议按以下格式输出：

```
【科技构成】
核心突破：[1-2句，最关键的技术创新]
自主化水平：[国产化率/卡脖子突破情况]
迁移潜力：[可应用到哪些其他场景]

【艺术构成】
造型语言：[视觉特征与设计逻辑]
情感唤起：[给人什么样的第一印象]
美学基因：[有无中国文化审美元素]

【人本构成】
核心用户：[谁在用，真实痛点是什么]
体验改善：[和前代方案相比提升了什么]
极端适应：[最恶劣条件下的表现]

【商业构成】
价值规模：[创造了多少经济价值]
产业带动：[上下游影响]
复制逻辑：[商业模式能否被复制推广]

【文化构成】
国家叙事：[代表了什么样的中国故事]
符号价值：[有没有成为文化标志]
传播策略：[用什么方式讲这个故事最有感染力]
```
