# YB-001 黄蓝叙事漫画 · v1.1.0


## 内容优先的表达构思

先理解内容，再设计讲法，最后应用视觉风格。本节优先于本Skill中的示例布局、默认页型及页数建议；用户明确指定的布局仍应遵守。模板固定视觉语言，不固定故事结构与构图。

生成前先形成一份简短表达简报：听众是谁；希望其理解、感受或采取什么行动；核心主张是什么；必须保留的事实、证据、限制与情绪转折是什么。已有信息足够就直接判断，不机械追问；只有影响讲法的关键缺失才询问。

根据内容选择叙事逻辑：故事按处境、变化、选择与结果推进；观点用依据、例子与成立条件支撑；机制明确参与者、作用和反馈；方法展示任务、操作与关键判断；选择按同维度比较与适用条件展开；文化表达可从生活细节、器物或场景进入。以上是候选讲法，不是另一组强制模板，允许混合或另创。

只有存在实质不同的讲法且用户尚未指定时，提出两种简短方向，解释各自突出什么；普通单页可自主选择，不把每次创作变成审批流程。单页确定表达任务，整套安排进入、推进、转折与停顿，再决定页数、构图、字图比例和视觉节奏。

封面、观点、对比等页型是参考词汇，不是必须凑齐的目录。允许纯文字页、证据页、连续场景或用户内容所需的新页型。不要为了套三步骤而改写过程、为了闭环添加因果、为了风格强放人物或器物；不能用通用口号替代原始细节。插画须解释动作、关系、证据或情绪，否则删掉或改为留白。

验收先看内容：能否说清本页为何采用这个讲法、图像增加了什么理解；原始事实、限定、情绪和关系是否保留；是否因套版发生删减、伪造或过度概括。再检查视觉一致性、文字可读性与尺寸。跨页保持字体、配色、笔触与必要角色一致，布局随内容变化。


## 适用与证据
用于成长故事、逻辑推演、旅程、方法与人机关系；不是所有主题都必须画成旅程。
用户认可黄蓝风格方向。assets/COVER.jpg 等八张是专用原创页型样页，已检查文字、关系与尺寸，待用户逐张审阅。assets/01.png 至08.png 为较早的连续推演参考。第三方员工旅程海报不随包分发。

## 固定视觉语法
- 白色底，黑色有机墨线，暖黄人物衣物与关键道具，浅蓝宽带表达连接、行程或空间。灰色仅为次级支撑。建议色值：#FFFFFF、#171717、#F5C94C、#A6C6E8、#D8D8D5；这些是规范化建议，不是原图精确取色。
- 成年人身体修长、四肢有弹性，姿态有方向，表情自然活泼。用动作讲述关系；避免幼儿大头、肥胖比例、写实机器人和僵硬商务图库人物。
- 线条有轻微手绘起伏但边缘清晰；少量黑色点描用于局部肌理，不铺满背景，不加复古纸噪点。
- 标题用醒目、略有不规则的中文手写黑体视觉；说明用清晰朴素的中文黑体视觉。不得声称图像生成使用了某个精确字体文件。整套保持同一字形气质。
- 蓝带是构图手段，不自动代表因果。必须用清楚的箭头和标签表达真正的关系；有反馈才画回路。

## 角色与连续性
先选一个原创主角并固定发型、眼镜、衣着颜色和身材，变化的是动作与镜头。可参考 assets/02.png、assets/04.png 的修长眼镜人物，但不强制所有主题使用同一个性别。连续推演锁定人、物、受益者的位置，每页只突出新增变化。风扇仅是当前案例，换主题须重新设计道具。

## 内容与复杂度
先提炼：受众、唯一主张、必留原文、关系、事实/假设状态。信息不足时依会话合理设计，不重复确认已确定风格。
短文观点页：一个主张、一个动作、最多一句解释，约 40–60% 留白。
中等内容：2–3 个场景、每场景 1–2 人、1–3 件必要道具，最多三个信息层级，约 30–40% 留白。
系统与长文：先保留关键节点、条件、关系；删装饰、合并重复说明，必要时拆页。不能靠缩小字体塞满。长文参考仅验证现有案例，不代表任意密度都适用。
建议最终1920画布：标题64–88px，节点32–44px，说明不小于28px；视觉验收优先于这些建议值。
不加无关盆栽、咖啡杯、办公室背景、仪表盘、装饰气泡。每页最多一条主要蓝带；除非关系需要，不画蛇形全程路线。

## 八种页型
- COVER 封面：大标题＋一个主角动作＋一个核心物件；蓝带引入主题。
- SECTION 章节：章节号、短标题、单个动作，留悬念。
- CLAIM 观点：一句大主张＋一个视觉隐喻，画面不复述整段论证。
- COMPARE 对比：同一人物、任务和尺度，两侧仅改变关键条件；不把并列画成时间先后。
- STEPS 方法：3–5 个步骤沿蓝带展开，明确起终点；并列方法用开放分组而非箭头。
- CYCLE 机制：3–4 节点和明确反馈边，人物融入节点；逐条校验方向。
- SYSTEM 系统：输入、核心关系、输出分组；蓝色表示组织范围，黄色突出当前关键环节。区分人类决定与机器行动。
- END 结尾：呼应封面主角，保留一句收束与行动邀请；用户要二维码时留空，不生成假码。

## 生成流程
1. 选页型并写一句本页主张；列出必须出现的文字和关系，禁止自行增加数据或把假说画成事实。
2. 查看 assets 中相关原图，用它作为风格锚点；参考锁定媒介与角色，不机械复制同一布局。
3. 使用 image 生成整页：文字、人物、关系、留白共同构图。不要用HTML卡片拼版冒充风格成品。
4. 提示词依次包含：本页意图、逐字文字、构图与箭头、人物身份、视觉语法、密度限制、画布留白。只输出指定文字，不加英文Takeaway等无关标签。
5. 检查实际文件尺寸，默认最终1920×1080；左右至少115px、上下81px内容安全区。原生尺寸不能冒充最终尺寸。若需适配，用等比缩放与同色补边，不拉伸、不裁切文字；若当前工具政策要求额外授权后处理，遵守工具要求并报告实际尺寸。
6. 查看成品，逐字核对中文、手指/手臂、角色一致性、箭头起终点、对比维度、假设边界。100%查看文字，再缩至投影观看尺度检查可读性。
7. 项目目录集中保存原图、成品、提示词与尺寸记录；不覆盖旧版。未通过的页型标候选，不以数量代替验收。
