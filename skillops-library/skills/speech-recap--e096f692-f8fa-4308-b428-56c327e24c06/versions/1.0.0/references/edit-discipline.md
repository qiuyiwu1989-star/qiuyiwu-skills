## 一、三条编辑纪律（写进 SKILL，也是硬约束）

线上脚本原文：

> 三条编辑纪律（写进 SYSTEM，也写进这里当注释存档）
> --------------------------------------------------
> 来自 SKILL.md 的「0. 定位」：这是记录，不是营销稿。
>   · 修口误、顺逻辑、回归真实——保留讲者第一人称口吻和真实措辞。
>   · 不做钩子标题、不替讲者拔高、不杜撰细节数据案例。
>   · 标点：中文正文一律弯引号，不用直角引号「」（除非是标题引用/新造术语/
>     品牌固定写法这三种例外，见 CLAUDE.md）。

**任务性质说明**（线上原文，很关键）：

> 这个模块的输入不是原子锚点，是一份完整的逐字稿。任务性质反过来了：
> 不是「防止编造」，是「**保真复述**」——逐字稿本身就是唯一真源，引擎要做的是
> **修口误、顺逻辑、分节配标题、控制密度，不删减实质内容、不添加逐字稿里
> 没有的判断/数据/案例。**

## 二、两样回扫（替代"编造防护"）

线上原文：

> ① **脱敏疑点扫描** —— 逐字稿里可能出现的客户名/竞品名/政府官员/身份证手机号
>    一类的敏感信息，正则+关键词初筛，**列出来交人复核，不自动删改**。
>    2026-08-19 处理"个人AGI搭建"那篇时，手工发现一处「现在的总理啊，当时是
>    我们的省长」——这种政治人物暗示级别的判断，规则目前判不出来，
>    所以扫描结果永远是「疑点清单」不是「已处理」，发布前必须人过一遍。
> ② **密度扫描** —— 复用 check_recap_standard.py 的密度公式（每 300-500 字一个
>    视觉停顿），初稿如果稀疏直接在生成阶段标出来。

## 三、脱敏疑点清单模板（交付用）

发布前**逐条列出**，交人复核（**不擅自处理**）：

```
【脱敏疑点】
1. 客户/合作方名
   原文：__（如"利丰"）
   建议：__（如"一家大型服装供应链企业"）
   理由：__（未获授权公开/竞品敏感）

2. 人名
   原文：__ / 建议：__ / 理由：__

3. 政治人物暗示（最难，规则判不出）
   原文：__
   建议：交人判断
   理由：可能是敏感联想

4. 自估数字
   原文：__（如"平均月收入两万五"）
   建议：是否加"约"/"据我估算"
   理由：讲者自估，非精确数据

5. 易对号入座的措辞
   原文：__（如"老登/中登/小登"）
   建议：是否改中性说法
   理由：特定场合可能被对号入座

6. 计划 vs 已实施
   原文：__（如"实习要收钱""不招正式员工"）
   检查：是否有"这是计划/当时的想法"这类限定句
   要求：限定句必须保留，不能写成已实施
```

## 四、常见坑

| 坑 | 表现 | 处理 |
|---|---|---|
| **转写不完整** | 飞书文字记录缺讲者部分段落 | 先核对总时长/段数，缺了**告知用户**，不自己补 |
| **口语数字** | "两万五""几个亿" | 保留原样或加"约"，**不要精确化成"25000"** |
| **代词指代不清** | "他说""这样做"离开上下文看不懂 | 可补主语，但**不改原意**（改动过大要标） |
| **把讲者的话写得比本人漂亮** | 加了排比/金句 | **回退**——记录不是文案 |
| **名场面被磨平** | 把"我宁可不做"改成"审慎决策" | **保留力度**，原话的力量就是实录的价值 |

## 五、一次真实案例（2026-10-25 OPC）

- **输入**：飞书文字记录（下午场，仅取邱懿武段落）+ 课件 37 页 PDF
- **产出**：10 章实录，结构六件齐，密度 245 字/停顿
- **脱敏处理**：
  - 客户名 → "一家大型服装供应链企业"/"一家大型家电企业"
  - "利丰/波司登/海尔" → 泛化
  - 团队同学 → 匿名
  - **保留**"郑老师"（公开场合、主办方）
  - **保留**"老登"段（按讲者最终处理："不只是年龄，而是自己不懂还站在别人背后指手画脚的状态"）
  - **保留**限定句"还是当时提出的计划，并不等于已经实施"
- **教训**：本地预览时发现 HTML 引绝对路径 CSS → `file://` 无样式。**本地看效果必须先抓 CSS 改相对路径。**
