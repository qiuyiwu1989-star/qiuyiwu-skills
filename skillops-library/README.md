# SkillOps 技能归档

这份快照来自 SkillOps 统一目录，包含 368 个技能、404 个可读版本和 1,970 个文件。目录中的 8 个插件另有索引。

- [全库索引](index.json)列出技能 ID、当前版本、历史版本和目录。
- `skills/<名称>--<ID>/index.json` 列出该技能每个版本的文件。
- `skills/<名称>--<ID>/versions/<版本>/` 保存对应的 `SKILL.md` 和接口返回的附件。

每份包保留源端提供的摘要。标有 `redactions` 的文件含已遮盖的疑似凭证，其归档字节与源包不同。插件索引只记录名称、ID 与版本，完整插件包由 SkillOps 管理。

根目录的 `skills/` 是原仓库的安装来源。这里的历史快照用于查阅和版本对照。
