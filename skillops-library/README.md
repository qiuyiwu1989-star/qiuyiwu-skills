# SkillOps 技能归档

这里保存了 SkillOps 统一技能目录的一份版本快照，共 **368 个技能、404 个可读版本、1,970 个文件**。从[全库索引](index.json)可以查技能名称、ID、当前版本和历史版本。

1. 在[全库索引](index.json)中找到技能，查看它的 `path`。
2. 打开该目录的 `index.json`，找到想查看的版本。
3. 进入 `versions/<版本>/`，阅读 `SKILL.md` 和该版本随附的模板、参考资料或脚本。

归档保留源端提供的包摘要。个别文件的疑似凭证已遮盖，对应文件在索引里标有 `redactions`。这类文件的归档字节与源包不同。目录中的 8 个插件提供名称、ID 和版本索引，完整插件包由 SkillOps 管理。

仓库的安装脚本对应根目录 `skills/` 下的三个技能。安装命令和技能示例见[仓库首页](../README.md)。
